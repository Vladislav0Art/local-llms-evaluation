### URI (URL)

A Uniform Resource Identifier (URI) is a string that uniquely identifies a resource on a network.

#### Types of URIs

*   HTTP (Hypertext Transfer Protocol) URIs: used for web protocols
*   FTP (File Transfer Protocol) URIs: used for file transfers
*   SMTP (Simple Mail Transfer Protocol) URIs: used for email communication
*   DNS (Domain Name System) URIs: used to map domain names to IP addresses

#### URI Components

A URI consists of several components:

1.  Protocol (e.g., HTTP, FTP)
2.  Hostname or IP address
3.  Port number (if applicable)
4.  Path (or URL path)
5.  Parameters (optional)
6.  Query string (optional)

#### URI Syntax

A URI typically follows this syntax:

```
protocol://hostname:port/path?query#fragment
```

For example:

*   `http://example.com/path/to/resource?param1=value1&param2=value2#anchor`
*   `ftp://user@host:port/path/to/file`
