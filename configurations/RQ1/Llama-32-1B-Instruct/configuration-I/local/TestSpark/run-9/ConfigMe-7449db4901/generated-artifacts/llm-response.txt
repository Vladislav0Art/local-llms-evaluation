```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // Create an empty map
        Map<String, List<String>> map = new HashMap<>();

        // Add some key-value pairs to the map
        map.put("test", Arrays.asList("line1"));
        map.put("test2", Arrays.asList("new-line"));

        System.out.println("Map Before Iteration:");
        printMap(map);

        // Iterate over all keys and values in the map
        for (Map.Entry<String, List<String>> entry : map.entrySet()) {
            String key = entry.getKey();
            List<String> value = entry.getValue();

            System.out.println("\nKey: " + key);
            System.out.println("Value: " + value);

            // Test 1: Get All Keys and Values as a Set of Key-Value Pairs
            System.out.println("\nAll Keys and Values (Set):");
            printMap(entry.getKey(), entry.getValue());
        }
    }

    public static void printMap(String prefix, List<String> map) {
        for (String key : map) {
            System.out.print(prefix + ": ");
            if (key != null && !key.isEmpty()) {
                System.out.println(key);
            } else {
                System.out.println("null");
            }
            System.out.println();
        }
    }
}
```

This code creates an empty `HashMap` and adds some key-value pairs to it. It then iterates over all keys and values in the map, prints each key and value along with its corresponding set of key-value pairs using the `printMap` method.

```
Value: [line1]
Key: test2
Value: [new-line]

Value: null
```
