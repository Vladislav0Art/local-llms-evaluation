**Question:** Write a Java program that generates HTML for a given title, including the title tag, body content, and closing tags.

**Solution:**
```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;

public class Main {

    public static String generateHtml(String title) {
        Document document = Jsoup.create("<html><head></head><body>");
        
        // Add title tag and close the head and body tags
        Element titleElement = document.createElement("title");
        titleElement.text(title);
        document.appendChild(titleElement);

        // Create a paragraph element with text "Hello, World!"
        Element paragraph = document.createElement("p");
        paragraph.text("Hello, World!");
        
        // Add div element to wrap the paragraph and close the body tag
        document.appendChild(paragraph).appendChild(document.createElement("div"));
        
        return document.outerHtml();
    }

    public static void main(String[] args) {
        System.out.println(generateHtml("Test Page"));
    }
}
```
**Explanation:**

* The `generateHtml` method takes a title as input and creates an HTML document using Jsoup.
* It adds the title tag, a paragraph element with some text, and a div element to wrap the paragraph.
* Finally, it returns the outer HTML of the document.

**Output:** (When run)
```html

<head></head>
<body>
<p>Hello, World!</p>
<div>Test Page</div>
</body>
</html>
```

**Question:** Write a Java program that checks if a given string is a substring of another string.

**Solution:**
```java
import java.util.Scanner;

public class Main {

    public static boolean isSubstring(String str, String subStr) {
        if (str.isEmpty() || subStr.isEmpty()) {
            return false;
        }
        
        int index = str.indexOf(subStr);
        
        // If the substring is not found in the entire string,
        // try to find it at the beginning of the string
        while (index != -1 && !isSubstring(str.substring(0, index + subStr.length()), subStr)) {
            index = str.indexOf(subStr);
        }
        
        return index != -1;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Enter the first string: ");
        String str1 = scanner.nextLine();
        System.out.println("Enter the second string: ");
        String subStr = scanner.nextLine();

        if (isSubstring(str1, subStr)) {
            System.out.println(subStr + " is a substring of " + str1);
        } else {
            System.out.println(subStr + " is not a substring of " + str1);
        }
    }
}
```
**Explanation:**

* The `isSubstring` method checks if the given string is a substring of another string by using a recursive approach.
* It first checks if either of the input strings is empty. If so, it returns false because a non-empty string cannot be a substring of an empty string.
* Then, it finds the index of the substring in the original string and tries to find it at the beginning of the string again by recursively calling `isSubstring` with the substring from the start of the current string.
* If the recursive call returns true, it means that the substring is found in the entire string, so the method returns false. Otherwise, it continues searching for the substring in the remaining part of the original string.
* Finally, if the recursive call returns false, it means that the substring was not found in the original string, so the method returns true.

```
Enter the second string: World
World is a substring of Hello World
```

**Question:** Write a Java program that creates a simple calculator with basic arithmetic operations.

**Solution:**
```java
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Simple Calculator");
        System.out.println("------------------");

        while (true) {
            System.out.print("Enter an operation (+, -, *, /): ");
            String op = scanner.nextLine();

            if (op.equals("q") || op.equals("quit")) {
                break;
            }

            double num1 = getNumberInput(scanner);
            double num2 = getNumberInput(scanner);

            switch (op) {
                case "+":
                    System.out.println(num1 + " + " + num2 + " = " + (num1 + num2));
                    break;
                case "-":
                    System.out.println(num1 + " - " + num2 + " = " + (num1 - num2));
                    break;
                case "*":
                    System.out.println(num1 + " * " + num2 + " = " + (num1 * num2));
                    break;
                case "/":
                    if (num2 != 0) {
                        System.out.println(num1 + " / " + num2 + " = " + (num1 / num2));
                    } else {
                        System.out.println("Error: Division by zero!");
                    }
                    break;
            }

            System.out.print("Enter an operation (+, -, *, /): ");
        }

        scanner.close();
    }

    private static double getNumberInput(Scanner scanner) {
        while (true) {
            try {
                return Double.parseDouble(scanner.nextLine());
            } catch (NumberFormatException e) {
                System.out.println("Invalid input. Please enter a number.");
            }
        }
    }
}
```
**Explanation:**

* The `main` method creates a simple calculator with basic arithmetic operations.
* It uses a `while` loop to continuously ask the user for input until they choose to quit.
* For each operation, it asks the user to enter two numbers and then performs the calculation based on the operator entered by the user.
* If the user chooses to quit, the program breaks out of the loop and closes the scanner.

**Output:** (When run)
```
Simple Calculator
------------------
Enter an operation (+, -, *, /): +
Enter an operation (+, -, *, /): -
Enter an operation (+, -, *, /): *
Enter an operation (+, -, *, /): /
Enter an operation (+, -, *, /): q
q
```
