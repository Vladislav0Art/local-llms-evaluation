Here is a sample Java code that generates a normalized query string:

```java
public class Main {

    public static void main(String[] args) {
        String inputQuery = "name=John&age=30";
        String encodedPath = normalizeQuery(inputQuery);
        System.out.println("Encoded Path: " + encodedPath);

        URL normalizedUrl = new java.net.URL("https://example.com/path")
                .query(normalizedPath)
                .build();
        System.out.println("Normalized URL: " + normalizedUrl.toExternalForm());
    }

    public static String normalizeQuery(String inputQuery) {
        // Remove leading and trailing spaces
        inputQuery = inputQuery.trim();

        // Replace multiple spaces with a single space
        inputQuery = inputQuery.replace(" ", "");

        // Split the query into individual key-value pairs
        String[] keyValuePairs = inputQuery.split("&");

        StringBuilder normalizedPath = new StringBuilder();
        StringBuilder normalizedQuery = new StringBuilder();

        for (String pair : keyValuePairs) {
            int index = pair.indexOf('=');
            if (index != -1) {
                String key = pair.substring(0, index).trim();
                String value = pair.substring(index + 1).trim();

                // Replace '+' with '+' and reformat the query string
                normalizedPath.append(key).append("=").append(value).append("&");
                normalizedQuery.append(key).append("=");
                normalizedQuery.append(value).append("&");
            }
        }

        // Remove trailing '&' and reformatted query string
        String normalizedQueryStr = normalizedQuery.toString().replaceAll("&$", "");

        return "path=" + encodedPath + "&query=" + normalizedQueryStr;
    }
}
```

In this code, we first remove leading and trailing spaces from the input query. Then, we replace multiple spaces with a single space.

Next, we split the query into individual key-value pairs using the '&' character as the delimiter.

We then iterate over each pair and extract the key and value. We remove any leading or trailing whitespace from both the key and value.

After that, we format the query string to include the '=' sign between the key and value, and append it to our `normalizedQueryStr`.

Finally, we add a '?' character after the path (if present) and append it to the normalized query string.

```java
import java.net.URI;
import java.util.ArrayList;
import java.util.List;

public class Main {

    public static void main(String[] args) {
        String inputQuery = "name=John&age=30";
        List<String> paths = normalizeQuery(inputQuery);
        System.out.println("Paths: " + paths);

        URI normalizedUrl = createNormalizedUrl(paths);
        System.out.println("Normalized URL: " + normalizedUrl.toExternalForm());
    }

    public static String normalizeQuery(String inputQuery) {
        // Remove leading and trailing spaces
        inputQuery = inputQuery.trim();

        // Replace multiple spaces with a single space
        inputQuery = inputQuery.replace(" ", "");

        // Split the query into individual key-value pairs
        String[] keyValuePairs = inputQuery.split("&");

        List<String> paths = new ArrayList<>();
        for (String pair : keyValuePairs) {
            int index = pair.indexOf('=');
            if (index != -1) {
                String key = pair.substring(0, index).trim();
                String value = pair.substring(index + 1).trim();

                // Replace '+' with '+' and reformat the query string
                paths.add(key + "=" + value);
            }
        }

        return "";
    }

    public static URI createNormalizedUrl(List<String> paths) {
        URI normalizedPath;
        if (paths.size() > 0) {
            String encodedPath = encodeURI(paths.get(0));
            normalizedPath = new URI("https://example.com/path", null, encodedPath, null);
        } else {
            normalizedPath = null;
        }

        return normalizedPath;
    }

    public static String encodeURI(String uri) {
        try {
            URI result = new URI(uri);
            return result.getScheme() + "://" + result.getHost();
        } catch (Exception e) {
            return "";
        }
    }
}
```

```java
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;

public class Main {

    public static void main(String[] args) {
        String inputQuery = "name=John&age=30";
        List<String> paths = normalizeQuery(inputQuery);
        System.out.println("Paths: " + paths);

        URI normalizedUrl = createNormalizedUrl(paths);
        System.out.println("Normalized URL: " + new java.net.URI(normalizedUrl).toExternalForm());
    }

    public static String normalizeQuery(String inputQuery) {
        // Remove leading and trailing spaces
        inputQuery = inputQuery.trim();

        // Replace multiple spaces with a single space
        inputQuery = inputQuery.replace(" ", "");

        // Split the query into individual key-value pairs
        String[] keyValuePairs = inputQuery.split("&");

        List<String> paths = new ArrayList<>();
        for (String pair : keyValuePairs) {
            int index = pair.indexOf('=');
            if (index != -1) {
                String key = pair.substring(0, index).trim();
                String value = pair.substring(index + 1).trim();

                // Replace '+' with '+' and reformat the query string
                paths.add(key + "=" + URLEncoder.encode(value, StandardCharsets.UTF_8.toString()));
            }
        }

        return "";
    }

    public static URI createNormalizedUrl(List<String> paths) {
        if (paths.isEmpty()) {
            return null;
        }

        StringBuilder encodedPath = new StringBuilder();
        for (String path : paths) {
            String[] parts = path.split("=");

            if (parts.length == 2) {
                encodedPath.append(URLEncoder.encode(parts[0], StandardCharsets.UTF_8.toString())).append("=");
            } else {
                encodedPath.append(URLEncoder.encode(parts[0], StandardCharsets.UTF_8.toString()));
            }

            if (paths.indexOf(path) < paths.size() - 1) {
                encodedPath.append("&");
            }
        }

        return new java.net.URI("https://example.com/path", null, encodedPath.toString(), null);
    }
}
```
