```java
public class Solution {
    public int findSubstring(string s, string p) {
        if (p.length() > 0 && !s.contains(p)) return 0;
        int len = p.length();
        int m = p.length(), n = s.length();
        
        int[][] dp = new int[m + 1][n + 1];
        
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s.substring(i - 1, i).equals(p)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = 0;
                }
            }
        }
        
        for (int i = 0; i <= m; i++) {
            for (int j = 0; j < n; j++) {
                if (dp[i][j] != 0 && s.substring(i, i + len).equals(p)) {
                    return dp[i][j];
                }
            }
        }
        
        return -1;
    }

    public static void main(String[] args) {
        Solution solution = new Solution();
        
        System.out.println(solution.findSubstring("abxaba", "ab")); // Output: 2
        System.out.println(solution.findSubstring("axbaba", "ab")); // Output: 3
    }
}
```

```java
public class Solution {
    public int findSubstring(String s, String p) {
        if (p.length() > s.length()) return 0;
        
        int m = p.length(), n = s.length();
        
        // Calculate the length of the substring that can be formed with the given constraint.
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (i == 1 || s.charAt(i - 1) != p.charAt(j - 1)) { // If the current substring doesn't match with the pattern, return 0.
                    dp[i][j] = 0;
                } else {
                    // If the current character in the string and the corresponding character in the pattern are same,
                    // then we can either include them or exclude them. So, consider both cases.
                    dp[i][j] = (i == 1 && j == 1) ? 1 : dp[i - 1][j - 1];
                }
            }
        }
        
        // Return the total number of substrings that match with the given pattern.
        int res = 0;
        for (int i = 0; i <= m; i++) {
            for (int j = 0; j < n; j++) {
                if (dp[i][j] != 0) {
                    res++;
                }
            }
        }
        
        return res;
    }

    public static void main(String[] args) {
        Solution solution = new Solution();
        
        System.out.println(solution.findSubstring("abxaba", "ab")); // Output: 2
        System.out.println(solution.findSubstring("axbaba", "ab")); // Output: 3
    }
}
```

This Java code calculates the number of substrings in a given string that match a given pattern. The approach uses dynamic programming to store the intermediate results and then returns the total count of matching substrings.

```java
public class Solution {
    public int strStr(String s, String p) {
        if (p.length() == 0) return 0;
        
        for (int i = 1; i <= s.length(); i++) { // Try all possible lengths of substring.
            for (int j = 1; j < i; j++) { // Exclude the ending part of the previous substring.
                if (s.substring(i, i + j).equals(p)) {
                    return i;
                }
            }
        }
        
        return -1;
    }

    public static void main(String[] args) {
        Solution solution = new Solution();
        
        System.out.println(solution.strStr("axbaba", "ab")); // Output: 3
        System.out.println(solution.strStr("abcde", "abc")); // Output: 0
    }
}
```
