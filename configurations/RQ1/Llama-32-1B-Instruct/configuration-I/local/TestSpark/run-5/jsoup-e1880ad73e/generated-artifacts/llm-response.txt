**Hash Table Implementation**

A hash table is a data structure that stores key-value pairs in an array using a hash function to map keys to indices. Here's an example implementation of a simple hash table in Java:

```java
import java.util.HashMap;

public class HashTable {
    private Map<String, String> map;
    private int size;

    public HashTable() {
        this.map = new HashMap<>();
        this.size = 10; // initial capacity
    }

    // Method to add an element into the hash table
    public void addElement(String key, String value) {
        if (map.containsKey(key)) {
            System.out.println("Key " + key + " already exists in the hash table.");
        } else {
            map.put(key, value);
            System.out.println("Key " + key + " added to the hash table.");
        }
    }

    // Method to retrieve an element from the hash table based on its key
    public String getElement(String key) {
        return map.get(key);
    }

    // Method to check if a key exists in the hash table
    public boolean containsKey(String key) {
        return map.containsKey(key);
    }

    // Method to get the size of the hash table
    public int getSize() {
        return map.size();
    }

    @Override
    public String toString() {
        System.out.println("HashTable{" +
                "map=" + map +
                ", size=" + size +
                '}';
    }
}
```
