## generate_url Function
### Purpose
The `generate_url` function generates a URL by combining a host and port number.

### Code
```java
public static String generateUrl(String host, int port) {
    return "http://" + host + ":" + port;
}
```

## Example Use Cases
- Generating a URL for the example.com domain with port 443.
- Generating a URL for the example.net domain with port 80.

### main Method
```java
public static void main(String[] args) {
    String host = "example.com";
    int port = 443;
    
    System.out.println(generateUrl(host, port));
}
```

This will output: `http://example.com:443`
