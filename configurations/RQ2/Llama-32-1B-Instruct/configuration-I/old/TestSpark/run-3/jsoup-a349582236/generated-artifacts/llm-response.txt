====================== Iteration #3 ======================
Here is a Java code that demonstrates the concept of encapsulation and access modifiers:

```java
public class TestClass {
    private static int privateStaticVariable = 10;
    public static int publicStaticVariable = 20;

    public void myMethod() {}

    private void privateMethod() {}
}

class InnerClass {
    public String innerString = "Hello, World!";
}

public class Main {
    public static void main(String[] args) {
        TestClass testObj = new TestClass();
        
        System.out.println("Public Static Variable: " + TestClass.publicStaticVariable);
        System.out.println("Private Static Variable: " + TestClass.privateStaticVariable);

        testObj.myMethod();

        InnerClass innerObj = new InnerClass();

        System.out.println("Inner String: " + innerObj.innerString);
    }
}
```

In this code, we have a `TestClass` with two static variables. We also have an `InnerClass` that has an instance variable and a method. The access modifiers (`public`, `private`) are used to control the visibility of these variables and methods.

The output of the program will be:

```
Public Static Variable: 20
Private Static Variable: 10
Inner String: Hello, World!
```
