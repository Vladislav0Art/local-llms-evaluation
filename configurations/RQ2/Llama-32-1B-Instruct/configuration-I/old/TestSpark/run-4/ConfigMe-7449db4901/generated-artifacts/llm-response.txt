```java
public class MyClass {
    // Private field
    private int myPrivateField;

    // Constructor
    public MyClass() {
        this.myPrivateField = 10;  // Default constructor
    }

    // Public method
    public void myPublicMethod() {
        System.out.println("Hello, World!");
    }

    // Public method with parameter
    public String myPublicMethod(int a) {
        return "Hello, " + a;
    }

    // Public method with string and int parameters
    public String myPublicMethod(String str, int a) {
        return "Hello, " + str + ", " + a;
    }

    // Private method
    private void myPrivateMethod() {
        System.out.println("I am private!");
    }

    // Constructor that takes an argument
    public MyClass(int b) {
        this.myPrivateField = b;  // Parameterized constructor
    }

    // Public method with same name as a static method, but different parameters and return type
    public String myPublicMethod() {
        return "Hello, World!";
    }

    // Static method that has no parameters or returns any value
    public static int add(int a, int b) {
        System.out.println("Adding " + a + " and " + b);
        return a + b;
    }
}
```

```java
public class MyClass {
    // Private field
    private int myPrivateField;

    // Constructor
    public MyClass() {
        this.myPrivateField = 10;  
    }

    // Public method
    public void myPublicMethod(String name) {
        System.out.println("Hello, " + name + "! I am a public method.");
    }

    // Private method
    private int getMyPrivateField() {
        return myPrivateField;
    }

    // Static method
    public static int myStaticMethod(int x) {
        return x * 2;
    }

    // Default constructor
    public MyClass() {
        System.out.println("Hello, default constructor.");
    }

    // Parameterized constructor
    public MyClass(int x, int y) {
        System.out.println("Hello, parameterized constructor with " + x + " and " + y + ".");
    }

    // Nested class
    private static class InnerClass {
        void myInnerMethod() {
            System.out.println("Hello, inner class method.");
        }
    }

    public static void main(String[] args) {
        MyClass obj1 = new MyClass();
        obj1.myPublicMethod("John");

        int x = 5;
        int y = 10;

        System.out.println("myPrivateField: " + getMyPrivateField());
        System.out.println("myStaticMethod(2): " + myStaticMethod(x));

        int[] scores = {80, 90};
        for (int score : scores) {
            System.out.println("Score: " + score);
        }

        obj1.myInnerMethod();
    }
}

class ExampleClass {
    public static void main(String[] args) {
        int x = 5;
        int y = 10;

        while (x < 20) {
            x += 2;
            System.out.println("x: " + x);
            if (x > 15) break;
        }

        for (int i = 1; i <= 10; i++) {
            System.out.println("Hello, " + i);
        }
    }
}
```

This program demonstrates the following concepts:

*   Encapsulation: The `myPrivateField` is private and can only be accessed within the same class.
*   Private method: A method with the same name as a private field is called a nested method or an inner method.
*   Static method: A static method belongs to the class, not to any instance of the class.
*   Default constructor: The default constructor is called when an object is created without specifying a constructor argument.
*   Parameterized constructor: A constructor with arguments is called when an object is created.
*   Nested classes: A nested class can be defined inside another class.
