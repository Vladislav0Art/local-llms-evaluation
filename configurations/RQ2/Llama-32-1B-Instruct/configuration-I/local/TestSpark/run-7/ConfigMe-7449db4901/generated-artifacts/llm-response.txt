**Problem:**
Design a simple online forum system that allows users to create accounts, post articles, add comments on articles, and delete their own account.

**Answer:**

```java
import java.util.*;

class User {
    private String username;
    private int id;

    public User(String username) {
        this.username = username;
        this.id = System.currentTimeMillis();
    }

    public String getUsername() {
        return username;
    }

    public int getId() {
        return id;
    }
}

class Article {
    private String title;
    private List<Comment> comments;

    public Article(String title) {
        this.title = title;
        this.comments = new ArrayList<>();
    }

    public void addComment(Comment comment) {
        comments.add(comment);
    }

    public List<Comment> getComments() {
        return comments;
    }
}

class Comment {
    private String text;
    private int id;

    public Comment(String text, int id) {
        this.text = text;
        this.id = id;
    }

    public String getText() {
        return text;
    }

    public int getId() {
        return id;
    }
}

public class ForumSystem {
    private User[] users;
    private Article[] articles;

    public ForumSystem(int numUsers, int numArticles) {
        this.users = new User[numUsers];
        this.articles = new Article[numArticles];

        for (int i = 0; i < numUsers; i++) {
            users[i] = new User("User" + i);
        }

        for (int i = 0; i < numArticles; i++) {
            articles[i] = new Article("Article " + i);
        }
    }

    /**
     * Login a user and return their username.
     *
     * @param username The username of the logged-in user
     * @return The username of the logged-in user
     */
    public String login(String username) {
        for (User u : users) {
            if (u.getUsername().equals(username)) {
                return u.getUsername();
            }
        }
        return null;
    }

    /**
     * Register a new user and add them to the forum.
     *
     * @param username The username of the new user
     */
    public void registerUser(String username) {
        User existingUser = getExistingUser(username);
        if (existingUser != null) {
            System.out.println("Username already taken!");
            return;
        }

        users[users.length - 1] = new User(username);

        for (Article article : articles) {
            article.addComment(new Comment("Comment on this article", existingUser.getId()));
        }
    }

    /**
     * Get the username of a logged-in user.
     *
     * @param username The username of the logged-in user
     * @return The username of the logged-in user
     */
    public String getUserUsername(String username) {
        for (User u : users) {
            if (u.getUsername().equals(username)) {
                return u.getUsername();
            }
        }
        return null;
    }

    /**
     * Get a list of all comments on an article.
     *
     * @param articleId The ID of the article
     * @return A list of Comment objects for the specified article
     */
    public List<Comment> getComments(int articleId) {
        Article article = getArticle(articleId);
        if (article == null) {
            return new ArrayList<>();
        }

        for (Comment comment : article.getComments()) {
            System.out.println(comment.getText());
        }
        return article.getComments();
    }

    private Article getArticle(int articleId) {
        for (Article article : articles) {
            if (article.getId() == articleId) {
                return article;
            }
        }
        return null;
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        ForumSystem system = new ForumSystem(10, 100);

        // Register users

        }
    }
```

This code defines a simple online forum system with features like user registration, login, article creation and deletion, and commenting. It provides methods to check if a username is taken, get the username of a logged-in user, get all comments on an article, and delete a user's account.

The `Main` class demonstrates how to use these classes to create a simple online forum. It registers users, logs in a user, gets their username, adds comments to articles, deletes a user's account, and checks if the comments are still available after deletion.
