```
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static List<String> getValuesByNames(String names) {
        // Convert the input string to a list of individual characters
        String charList = "";
        for (char c : names.toCharArray()) {
            charList += c;
        }

        // Get the unique values in the list
        Set<Character> uniqueChars = new HashSet<>();
        for (char c : charList) {
            uniqueChars.add(c);
        }
        List<String> result = new ArrayList<>();
        for (Character c : uniqueChars) {
            result.add(String.valueOf(c));
        }

        return result;
    }

    public static void main(String[] args) {
        System.out.println(getValuesByNames("P"));
        System.out.println(getValuesByNames("p"));
    }
}
```

This solution works by converting the input string to a list of individual characters, then using a `HashSet` to remove duplicates and get unique characters. It then converts each character back to a string and returns the result as a list of strings.
