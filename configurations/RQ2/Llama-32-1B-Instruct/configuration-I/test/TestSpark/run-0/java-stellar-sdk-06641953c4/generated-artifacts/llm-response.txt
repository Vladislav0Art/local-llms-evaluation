Here is an example:

```java
class PublicClass {
    public static void main(String[] args) {
        // Using private variable
        int privateVariable = 10;

        // Creating a new instance of class and accessing its method
        Main m = new Main();
        System.out.println(m.publicMethod());

        // Modifying a non-static variable inside the method
        PublicClass publicClass = new PublicClass();
        publicClass.nonStaticVariable = "Modified";

        System.out.println(publicClass.nonStaticVariable);
    }

    public int publicMethod() {
        return 1;
    }
}

class NonPublicClass {
    private static int nonStaticVariable = 20;

    public void nonStaticMethod() {
        System.out.println(nonStaticVariable);
    }
}
```

In this example:

- We have a `public` method in the `Main` class.
- We create an instance of `PublicClass` and call its `publicMethod()` method to access its value.
- We also create an instance of `NonPublicClass` and use its non-static variable to print its value.

I can provide a Java code example to demonstrate how to declare and use access modifiers in classes.

Here is an example:

```java
class PublicClass {
    public static void main(String[] args) {
        // Using private variable
        int privateVariable = 10;

        // Creating a new instance of class and accessing its method
        PublicClass m = new PublicClass();
        System.out.println(m.publicMethod());

        // Modifying a non-static variable inside the method
        PublicClass publicClass = new PublicClass();
        publicClass.nonStaticVariable = "Modified";

        // Using private and protected variables
        public static class Private {
            protected int protectedVariable = 30;

            public void protectedMethod() {
                System.out.println(protectedVariable);
            }
        }

        // Creating an instance of class and accessing its methods
        PublicClass privateClass = new Private();
        privateClass.protectedMethod();

        // Using public variables
        System.out.println("Public Variable: " + PublicClass.publicVariable);

        // Using static variable
        System.out.println("Static Variable: " + PublicClass.staticVariable);
    }

    public int publicMethod() {
        return 1;
    }

    private int privateVariable = 20;

    protected class ProtectedClass {
        private int protectedVariable = 40;

        public void protectedMethod() {
            System.out.println(protectedVariable);
        }
    }

    static int staticVariable = 50;

    public static void main(String[] args) {
        // Accessing variables using their access modifiers
        System.out.println(PublicClass.privateVariable);  // Output: 20

        System.out.println(Private.protectedVariable);  // Output: 30

        PublicClass.publicClass.nonStaticVariable = "New Value";

        System.out.println(PublicClass.publicVariable);  // Output: New Value
    }
}
```

In this example:

- We declare access modifiers (private, protected, public) for variables and methods.
- We use these access modifiers to control the accessibility of variables and methods in our classes.
