**How to Convert HTML to Jsoup:**

To convert HTML to Jsoup, you can use the `fromJsoup` method provided by the Jsoup library.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

public class Main {
    public static void main(String[] args) {
        // create a string containing html content
        String html = "<html><body>Hello <span>World!</span></body></html>";

        // convert the string to Jsoup Document object
        Document doc = Jsoup.parse(html);

        // access properties and methods of the Jsoup Document object
        System.out.println(doc.body().text());  // prints "Hello World!"

        // check the source code of the Jsoup Document object
        System.out.println(doc.toString());   // prints "<html><body>Hello <span>World!</span></body></html>"
    }
}
```

**How to Convert String to Jsoup:**

To convert a string to Jsoup, you can use the `toJsoup` method provided by the Jsoup library.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

public class Main {
    public static void main(String[] args) {
        // create a string containing html content
        String html = "<html><body>Hello <span>World!</span></body></html>";

        // convert the string to Jsoup Document object
        Document doc = Jsoup.parse(html);

        // print the parsed html content
        System.out.println(doc.body().text());  // prints "Hello World!"

        // check the source code of the Jsoup Document object
        System.out.println(doc.toString());   // prints "<html><body>Hello <span>World!</span></body></html>"
    }
}
```

Note that both methods assume that the input string is a valid HTML document. If the input string contains any invalid HTML elements or attributes, you may need to use additional libraries or tools to parse it correctly.
