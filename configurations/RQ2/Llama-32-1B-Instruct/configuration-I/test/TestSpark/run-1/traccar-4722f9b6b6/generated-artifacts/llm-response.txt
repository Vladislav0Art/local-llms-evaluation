```java
import java.net.Socket;
import java.nio.ByteBuffer;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) throws Exception {
        String result = "Some Message Count";
        
        // Create a Socket object
        Socket clientSocket = new Socket();
        
        // Define the socket address
        Address clientAddress = new Address("127.0.0.1", 12345);
        
        // Connect to the server
        clientSocket.connect(clientAddress, result.length());
        
        Scanner scanner = new Scanner(System.in);

        System.out.println("Server: " + result);
        while (true) {
            System.out.print("Client: ");
            String message = scanner.nextLine();
            
            if (!message.isEmpty()) {
                // Encode the user's input into bytes
                ByteBuffer buffer = ByteBuffer.wrap(message.getBytes());
                
                // Decode the message from the socket
                Object decodedMessage = Decoder.decode(clientSocket, clientAddress, buffer);
                
                System.out.println("Client: " + decodedMessage);
            } else {
                break;
            }
        }

        scanner.close();
    }
}

class Address {
    public String value;
}
```

This code creates a `Socket` object and connects it to the server. It then enters a loop where it continuously prompts the client for input, encodes the user's message into bytes, decodes the message from the socket, and prints the decoded message.

Note: This is a very basic example of how you can use the `Decoder` class in Java. In real-world applications, you would typically want to handle errors and exceptions more robustly.

import java.net.Socket;

import java.util.Scanner;

public class Main {
