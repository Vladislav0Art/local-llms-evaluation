The issue you're facing is likely due to the lack of implementation for the clone method in Java. By default, Java does not have a built-in clone method for objects, which means that when you try to create a copy of an object using the clone method, it will throw an exception.

To implement the clone method, you can override the Cloneable interface and provide a clone method that creates a new instance of your class. Here's an example:

```java
public class Comment implements Cloneable {
    private String text;

    public Comment(String text) {
        this.text = text;
    }

    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}
```

In the above code, we're implementing the Cloneable interface and overriding the clone method. The clone method creates a new instance of our class using the `super.clone()` call and returns it.

Alternatively, you can also use the deep copy approach to create a new Comment object that is a copy of the original comment:

```java
public class Comment {
    private String text;

    public Comment(String text) {
        this.text = text;
    }

    public static Comment clone(Comment comment) {
        return new Comment(comment.text);
    }
}
```

In the above code, we're providing a static method called `clone` that creates a new instance of our class and sets its text property to the value of the original comment.
