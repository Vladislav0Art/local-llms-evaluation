```java
    private Stack<Integer> stack;
    public int next(int price) { 
        while (!stack.isEmpty() && stack.peek() <= price) {
            stack.pop();
        }
        if (stack.isEmpty()) {
            span = 1;
        } else {
            span = price - stack.peek() + 1;
        }
        stack.push(price);
        return span;
    }

    private int span;

    public int[] calculateSpans(int[] prices) { 
        int n = prices.length, res[] = new int[n];
        stack = new Stack<>();
        for (int i = 0; i < n; i++) {
            if (i == 0 || next(prices[i]) > next(prices[i-1])) {
                span = next(prices[i]);
            }
            res[i] = span;
        }
        return res;
    }
}
```

```java
public class OnlineStockSpan {
    private Stack<Integer> stack;

    public OnlineStockSpan() {
        this.stack = new Stack<>();
    }

    /**
     * Returns the span of the current price, which is the number of consecutive days 
     * where the price was higher than or equal to the previous day's price.
     */
    public int next(int price) { 
        while (!stack.isEmpty() && stack.peek() <= price) {
            stack.pop();
        }
        if (stack.isEmpty()) {
            span = 1;
        } else {
            span = price - stack.peek() + 1;
        }
        stack.push(price);
        return span;
    }

    private int span;

    /**
     * Calculates the spans for all prices in the given array and returns them as an array.
     */
    public int[] calculateSpans(int[] prices) { 
        int n = prices.length, res[] = new int[n];
        stack = new Stack<>();
        for (int i = 0; i < n; i++) {
            if (i == 0 || next(prices[i]) > next(prices[i-1])) {
                span = next(prices[i]);
            }
            res[i] = span;
        }
        return res;
    }

    public static void main(String[] args) {
        OnlineStockSpan onlineStockSpan = new OnlineStockSpan();
        int[] prices = {100, 80, 75, 70, 60, 65};
        int[] result = onlineStockSpan.calculateSpans(prices);
        for (int i : result) {
            System.out.print(i + " ");
        }
    }
}
```

This code implements a solution to the Online Stock Span problem using a stack data structure. The `next` method calculates the span of each price, and the `calculateSpans` method uses this information to calculate the spans for all prices in the array and returns them as an array.

The time complexity of this solution is O(n), where n is the number of elements in the input array, since each element is pushed onto the stack exactly once. The space complexity is also O(n) because in the worst case, all elements are stored on the stack.
