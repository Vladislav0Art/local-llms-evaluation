====================== Iteration #1 ======================
1. DO NOT use @Before and @After test methods.
 2. Make test cases as atomic as possible.
 3. All tests should be written using JUnit 4.
 4. When mocking, use Mockito 5. However, DO NOT use mocking for all test cases.
 5. Name ALL methods according to the template: `[MethodUnderTest][Scenario]Test`. Use only English letters.

import java.net.URL;

@RunWith(MockitoJUnitRunner.class)

    public void buildUrlTest() throws Exception {
        // Given
        URL inputUrl = new URL("http://example.com/path?key1=value1&key2=value2#anchor");
