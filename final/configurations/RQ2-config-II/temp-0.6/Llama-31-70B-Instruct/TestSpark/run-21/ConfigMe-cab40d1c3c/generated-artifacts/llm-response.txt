1. Assert that the root entries map is empty when a new PropertyListBuilder is created.
2. Assert that adding a property to the builder adds an entry to the map and the property is retrievable by key.
3. Assert that adding a property to the builder with a path that already exists throws an exception.
4. Assert that creating a list of properties from the builder returns a list ordered by insertion order but grouped by path.

import static org.junit.Assert.*;

    public void addProperty_createsNewEntry() {
        // Arrange
        PropertyListBuilder propertyListBuilder = new PropertyListBuilder();

        // Act
