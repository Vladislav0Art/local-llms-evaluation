====================== Iteration #1 ======================
1. Test cases should be written using JUnit 4.
2. When mocking, use Mockito 5.
3. Mocking should be used only when necessary.
4. Tests should be written using the provided template: `[MethodUnderTest][Scenario]Test`.
5. Tests should be as atomic as possible.

package org.traccar.protocol;

    private WatchProtocolDecoder watchProtocolDecoder;

    }

    }
}
