Here's a Java code that demonstrates how to use Spring Boot's `@Value` annotation to inject properties into a Java application:

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.annotation.Value;

@SpringBootApplication
public class PropertiesApp {

    @Value("${name}")
    private String name;

    @Value("${age}")
    private int age;

    public static void main(String[] args) {
        SpringApplication.run(PropertiesApp.class, args);
    }

    public void printNameAndAge() {
        System.out.println("My Name is " + name + " and I am " + age + " years old.");
    }
}
```

In the above code:

*   We have a Spring Boot application with `@SpringBootApplication` annotation.
*   The `name` property is injected using `@Value("${name}")`, which looks for a property named `name` in the application's properties file (usually `application.properties` or `application.yml`) and injects its value into the `name` field.
*   The `age` property is also injected using `@Value("${age}")`.
*   We have a method called `printNameAndAge()` which prints out the name and age of the person.

The properties file (`application.properties`):

```properties
name=John Doe
age=30
```

This code will output:

```
My Name is John Doe and I am 30 years old.
```

If you don't have any properties defined in your `application.properties` or `application.yml`, this code will throw an exception.

The configuration file (`application.properties`) can also be used to inject values into other classes and methods by using the same annotation.

Here's a Java class that demonstrates how to use the `@Value` annotation in Spring Boot to read configuration properties from a file:

```java
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

@Component
@ConfigurationProperties(prefix = "person")
public class Person {

    private String name;
    private int age;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        this.age = age;
    }
}
```

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class ConfigurationPropertiesApp {

    public static void main(String[] args) {
        SpringApplication.run(ConfigurationPropertiesApp.class, args);
    }

    public static void printPersonInfo() {
        Person person = new Person();
        System.out.println("Name: " + person.getName());
        System.out.println("Age: " + person.getAge());
    }
}
```

`application.properties`:

```properties
person.name=John Doe
person.age=30
```

In the above code:

*   The `Person` class is annotated with `@Component`, indicating that it's a Spring-managed bean.
*   The `Person` class is also annotated with `@ConfigurationProperties(prefix = "person")`, which tells Spring to look for properties starting with `person.` in the configuration file and bind them to the corresponding fields.
*   In the `printPersonInfo()` method, we create an instance of the `Person` class and print out its name and age.
