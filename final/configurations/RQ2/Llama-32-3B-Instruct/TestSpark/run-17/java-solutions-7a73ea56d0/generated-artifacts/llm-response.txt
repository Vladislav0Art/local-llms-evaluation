```java
public class OnlineStockSpan {

    private Stack<Integer> stack;

    public OnlineStockSpan() {
        this.stack = new Stack<>();
    }

    public int next(int price) {
        if (!stack.isEmpty()) {
            while (!stack.isEmpty() && stack.peek() <= price) {
                stack.pop();
            }
            return stack.isEmpty() ? 1 : stack.peek() + 1;
        } else {
            return 1;
        }
    }

    public int[] calculateSpans(int[] prices) {
        int n = prices.length;
        int[] result = new int[n];
        stack.clear();
        for (int i = 0; i < n; i++) {
            result[i] = next(prices[i]);
            stack.push(prices[i]);
        }
        return result;
    }

}
```

```java
            while (!stack.isEmpty() && stack[stack.length - 1] <= prices[i]) {
                int top = stack[stack.length - 1];
                stack.remove(stack.length - 1);

                    count++;
```

```java
import java.util.Stack;

public class StockSpanner {
    public int[] stockSpanners(int[] prices) {
        Stack<Integer> stack = new Stack<>();
        int[] result = new int[prices.length];

        for (int i = 0; i < prices.length; i++) {
            while (!stack.isEmpty() && prices[i] >= prices[stack.peek()]) {
                stack.pop();
            }

            if (!stack.isEmpty()) {
                result[i] = stack.peek() - i;
            } else {
                result[i] = i + 1;
            }

            stack.push(i);
        }

        return result;
    }

    public static void main(String[] args) {
        StockSpanner stockSpanner = new StockSpanner();
        int[] prices = {100, 80, 75, 70, 60, 85};
        System.out.println(java.util.Arrays.toString(stockSpanner.stockSpanners(prices)));
    }
}
```

This code uses a Stack to keep track of the indices of the prices array. For each price in the array, it pops elements from the stack until it finds a price that is lower than the current price or the stack becomes empty. The number of times the top element was popped plus one is the span of the current price. If the stack is empty after popping all the elements, the span is set to the current index plus one.

Note: This solution assumes that the input array `prices` contains at least two distinct prices (if all prices are the same, it will return an array with all elements equal to their indices).
