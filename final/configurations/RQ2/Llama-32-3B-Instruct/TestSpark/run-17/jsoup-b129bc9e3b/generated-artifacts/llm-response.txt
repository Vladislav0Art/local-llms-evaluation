### Using Jsoup to Parse HTML

Jsoup is a lightweight, easy-to-use HTML parser for Java. It's well-suited for parsing HTML documents from web pages or strings.

#### Installing Jsoup

To use Jsoup in your project, you can add it as a dependency in your `pom.xml` file (if you're using Maven):

```xml
<dependency>
    <groupId>org.jsoup</groupId>
    <artifactId>jsoup</artifactId>
    <version>1.14.3</version>
</dependency>
```

#### Parsing HTML with Jsoup

Here's an example of how to parse an HTML string using Jsoup:

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class HtmlParser {

    public static String parseHtml(String html) {
        Document doc = Jsoup.parse(html);
        return doc.toString();
    }

    public static void main(String[] args) throws Exception {
        String url = "http://example.com";
        System.out.println(parseHtml(Jsoup.connect(url).get().html()));
    }
}
```

In this example, we're connecting to a URL using Jsoup's `connect` method and retrieving the HTML content of the page. We then pass this HTML string to our `parseHtml` method, which uses Jsoup to parse the HTML.

#### Parsing HTML from a File

If you have an HTML file on your local machine, you can use Jsoup to read it:

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

public class HtmlParser {

    public static String parseHtml(String filePath) throws Exception {
        Document doc = Jsoup.parse(filePath);
        return doc.toString();
    }

    public static void main(String[] args) throws Exception {
        String filePath = "path_to_your_html_file.html";
        System.out.println(parseHtml(filePath));
    }
}
```

#### Selecting Elements from HTML

Once you've parsed the HTML, you can select specific elements using Jsoup's `select` method:

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.select.Elements;

public class HtmlParser {

    public static void main(String[] args) throws Exception {
        String html = "<html><body>Hello World!</body></html>";
        Document doc = Jsoup.parse(html);

        // Select all paragraphs
        Elements paragraphs = doc.select("p");
        for (Element paragraph : paragraphs) {
            System.out.println(paragraph.text());
        }
    }
}
```

In this example, we're selecting all `p` elements from the HTML and printing their text content.

#### Creating a Document from an HTML String

You can also create a document directly from an HTML string without connecting to a URL:

```java

```

In this example, we're creating a document directly from the HTML string and printing its contents.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class HtmlParser {

    public static String parseHtml(String html) {
        Document doc = Jsoup.parse(html);
        return doc.toString();
    }

    public static void main(String[] args) throws Exception {
        // Parse HTML from a URL
        String url = "http://example.com";
        System.out.println("Parsing HTML from URL: " + url);

        Document doc = Jsoup.connect(url).get();
        System.out.println(doc.toString());

        // Extract all links on the page
        Elements links = doc.select("a[href]");
        for (Element link : links) {
            String href = link.attr("href");
            System.out.println(href);
        }

        // Parse HTML from a file
        String filePath = "/path/to/your/html/file.html";
        System.out.println("\nParsing HTML from file: " + filePath);

        doc = Jsoup.parse(filePath);
        System.out.println(doc.toString());

        // Extract all paragraphs on the page
        Elements paragraphs = doc.select("p");
        for (Element paragraph : paragraphs) {
            String text = paragraph.text();
            System.out.println(text);
        }
    }
}

        // assert
    }

        // assert
    }
}
```

**Explanation:**

1.  We start by importing the necessary classes from Jsoup.
2.  The `parseHtml` method takes an HTML string as input, parses it using Jsoup's `Jsoup.parse()` method, and returns the parsed HTML as a string.
3.  In the `main` method:

    *   We parse HTML from a URL using Jsoup's `Jsoup.connect()` and `get()` methods.
    *   We extract all links on the page by selecting elements with the "a[href]" class and iterating over them.
    *   We parse HTML from a file using Jsoup's `Jsoup.parse()` method.
    *   We extract all paragraphs on the page by selecting elements with the "p" tag and iterating over them.
