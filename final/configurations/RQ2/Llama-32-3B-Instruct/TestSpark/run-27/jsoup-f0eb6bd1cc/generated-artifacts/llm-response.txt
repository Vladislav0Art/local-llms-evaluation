It seems like you didn't ask a specific question, but I'll provide a general answer.

To build a URL in Java, you can use the `UrlBuilder` class. Here's an example of how you can do it:

```java
import java.net.URI;
import java.net.URISyntaxException;

public class UrlBuilder {
    private String scheme;
    private String authority;
    private String path;
    private String query;
    private String fragment;

    public UrlBuilder(String scheme) {
        this.scheme = scheme;
    }

    public UrlBuilder authority(String authority) {
        this.authority = authority;
        return this;
    }

    public UrlBuilder path(String path) {
        this.path = path;
        return this;
    }

    public UrlBuilder query(String query) {
        this.query = query;
        return this;
    }

    public UrlBuilder fragment(String fragment) {
        this.fragment = fragment;
        return this;
    }

    @Override
    public String toString() {
        try {
            URI uri = new URI(scheme, authority, path, query, fragment);
            return uri.toString();
        } catch (URISyntaxException e) {
            throw new RuntimeException(e);
        }
    }
}
```

You can use the `UrlBuilder` class as follows:

```java
public class Main {
    public static void main(String[] args) {
        UrlBuilder url = new UrlBuilder("https");
        url.authority("example.com").path("/path/to/resource").query("param=value")
                .fragment("#anchor");

        System.out.println(url.toString());
    }
}
```

This will output: `https://example.com/path/to/resource?param=value#anchor`
