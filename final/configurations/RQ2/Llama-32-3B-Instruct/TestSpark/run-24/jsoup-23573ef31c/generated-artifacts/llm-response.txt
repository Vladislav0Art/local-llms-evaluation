import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class WebScraper {

    public static void main(String[] args) {
        // Connect to the website
        Document document = Jsoup.connect("http://example.com").get();

        // Extract all links on the page
        Elements links = document.select("a");
        for (Element link : links) {
            String text = link.text();
            String url = link.attr("href");
            System.out.println(text + ": " + url);
        }

        // Find all images on the page
        Elements images = document.select("img");
        for (Element image : images) {
            String src = image.attr("src");
            System.out.println(src);
        }

        // Extract the title of the page
        Element title = document.title();
        System.out.println(title);

        // Get all paragraphs on the page
        Elements paragraphs = document.select("p");
        for (Element paragraph : paragraphs) {
            String text = paragraph.text();
            System.out.println(text);
        }
    }
}

4.  Similarly, we find all images on the page using `document.select("img")`, extract their sources, and print them.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class WebScraper {

    public static void main(String[] args) {
        // Connect to the website
        Document document = Jsoup.connect("https://www.example.com")
                .userAgent("Mozilla/5.0")
                .timeout(10000)
                .get();

        if (document != null) {
            // Extract all links on the page
            Elements links = document.select("a[href]");
            for (Element link : links) {
                String text = link.text();
                String url = link.attr("href");
                System.out.println(text + ": " + url);
            }

            // Find all images on the page
            Elements images = document.select("img[src]");
            for (Element image : images) {
                String src = image.attr("src");
                System.out.println(src);
            }

            // Extract the title of the page
            Element title = document.selectFirst("title");
            if (title != null) {
                System.out.println(title.text());
            } else {
                System.out.println("Title not found.");
            }

            // Get all paragraphs on the page
            Elements paragraphs = document.select("p");
            for (Element paragraph : paragraphs) {
                String text = paragraph.text();
                System.out.println(text);
            }
        } else {
            System.out.println("Failed to retrieve the webpage.");
        }
    }
}
```

In this code:

1.  We use `Jsoup.connect()` to connect to the specified URL.
2.  The `get()` method is used to fetch the HTML content of the webpage.
3.  We set a user agent and timeout for the request using `userAgent()` and `timeout()`, respectively, for better compatibility and performance.
4.  We select all links on the page using `document.select("a[href]")` and iterate over them, printing their text and URLs.
5.  Similarly, we find all images on the page using `document.select("img[src]")`.
6.  The title of the webpage is accessed using `document.selectFirst("title")`, ensuring that we don't throw a `NullPointerException`.
7.  Finally, we select all paragraphs (`p` elements) on the page using `document.select("p")`, and iterate over them, printing their text.

This code snippet demonstrates how to use Jsoup to extract data from a specific webpage in a more comprehensive manner.
