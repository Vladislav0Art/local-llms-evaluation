To build a URL from scratch using Java, you can use the `URI` class and its builder pattern to construct a new URI object.

Here's an example of how to do it:

```java
public class UrlBuilder {
    private String scheme;
    private String host;
    private int port;
    private String path;

    public UrlBuilder(String scheme, String host) {
        this.scheme = scheme;
        this.host = host;
    }

    public UrlBuilder withPort(int port) {
        this.port = port;
        return this;
    }

    public UrlBuilder withPath(String path) {
        this.path = path;
        return this;
    }

    public URI buildUrl() {
        if (port == 0) {
            String protocol = scheme.toLowerCase();
            if (protocol.equals("http")) {
                return new URI(protocol, host, DEFAULT_PORT, "/" + path);
            } else if (protocol.equals("https")) {
                return new URI(protocol, host, DEFAULT_PORT, "/" + path);
            }
        }
        return new URI(scheme, host, port, "/" + path);
    }

    private static final int DEFAULT_PORT = 80;
}
```

And here's an example of how to use it:

```java
public class GeneratedTest {

    public static void main(String[] args) {
        UrlBuilder urlBuilder = new UrlBuilder("http", "localhost");
        urlBuilder.withPort(8080).withPath("/api/v1").buildUrl();
        assertEquals(new URI("http", "localhost", 8080, "/", "/api/v1"), urlBuilder.buildUrl());

        urlBuilder = new UrlBuilder("https", "localhost");
        urlBuilder.withPort(8443).withPath("/test/path").buildUrl();
        assertEquals(new URI("https", "localhost", 8443, "/", "/test/path"), urlBuilder.buildUrl());
    }
}
```
