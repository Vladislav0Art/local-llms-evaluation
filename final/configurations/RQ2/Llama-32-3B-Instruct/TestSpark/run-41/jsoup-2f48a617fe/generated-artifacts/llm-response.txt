```java
public class Comment {
    private String data;

    public Comment(String data) {
        this.data = data;
    }

    public String getData() {
        return data;
    }

    public void setData(String data) {
        this.data = data;
    }

    @Override
    public String toString() {
        return "Comment{" +
                "data='" + data + '\'' +
                '}';
    }
}
```

This comment class has a constructor that takes a `String` parameter, which is used to store the comment's data. The `getData()` method returns the stored data, and the `setData(String)` method allows you to update the data.

You can use this class as follows:

```java
public static void main(String[] args) {
    Comment comment = new Comment("This is a sample comment.");
    System.out.println(comment.toString());
}
```

This will output: `Comment{data='This is a sample comment.'}`
