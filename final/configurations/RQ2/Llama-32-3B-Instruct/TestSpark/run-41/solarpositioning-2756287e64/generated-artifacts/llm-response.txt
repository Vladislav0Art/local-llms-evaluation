```java
import java.time.ZonedDateTime;
import java.util.Random;

public class Grena3 {
    public static AzimuthZenithAngle calculateSolarPosition(ZonedDateTime date, double latitude, double longitude) {
        // Convert date to local solar time (LST)
        ZonedDateTime lstDate = date.withZoneSameInstant(ZoneId.of("UTC"));
        double hourAngle = Math.atan2(Math.sin(lstDate.getHour() * 15 + lstDate.getMinute() / 60.0), Math.cos(lstDate.getHour() * 15 + lstDate.getMinute() / 60.0));
        
        // Calculate sun's altitude and azimuth
        double sunAltitude = Math.asin(Math.sin(latitude * Math.PI / 180) * Math.sin(hourAngle * Math.PI / 180));
        double sunAzimuth = Math.atan2(Math.cos(sunAltitude) * Math.sin(hourAngle), Math.cos(sunAltitude) * Math.cos(hourAngle));

        // Convert hour angle to local solar time (LST)
        double localSolarTime = (hourAngle + longitude * 15 / 180) % 24;
        
        return new AzimuthZenithAngle(sunAzimuth * 360 / Math.PI, sunAltitude * 90 / Math.PI);
    }

    public static void main(String[] args) {
        ZonedDateTime now = ZonedDateTime.now();
        Random rand = new Random();

        for (int i = 0; i < 10; i++) {
            double latitude = rand.nextDouble() * 180 - 90;
            double longitude = rand.nextDouble() * 360 - 180;

            AzimuthZenithAngle result = Grena3.calculateSolarPosition(now, latitude, longitude);
            System.out.println("Testing with date: " + now);
            System.out.println("With latitude: " + latitude);
            System.out.println("With longitude: " + longitude);

            System.out.println(result.azimuth + ", " + result.zenith);
        }
    }
}
```
This code calculates the solar time (LST) for a given date and location, then uses this value to calculate the sun's altitude and azimuth at that specific moment. The results are printed out in degrees, with the azimuth ranging from 0-360 and the zenith ranging from 0-90.

Please note that this is a simplified model and does not account for various factors such as atmospheric refraction, which can affect the accuracy of the results.

Also, it's worth noting that this code assumes that the longitude value is in degrees. If it's in some other unit, you may need to convert it before using it in the calculation.

The `calculateSolarPosition` method returns an object containing two values: `azimuth` and `zenith`, which represent the sun's position in the sky at a given time. These values are calculated using the formula:

* `hourAngle = atan2(sin(LST_hour) * sin(latitude), cos(LST_hour) * cos(latitude))`
* `sunAltitude = arcsin(sin(azimuth) * sin(latitude))`
* `sunAzimuth = atan2(cos(sunAltitude) * sin(azimuth), cos(sunAltitude) * cos(azimuth))`

where LST is the local solar time, and azimuth is the angle from true south to the sun.

The results are then converted back to degrees using the following formulas:

* `azimuth = (hourAngle + longitude * 15 / 180) % 24`
* `zenith = (arcsin(sin(azimuth) * sin(latitude))) * 90 / PI`

These conversions ensure that the resulting values are in the correct units and are easy to understand.
