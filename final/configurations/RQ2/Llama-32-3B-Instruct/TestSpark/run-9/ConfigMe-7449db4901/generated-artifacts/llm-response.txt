**Problem:** Write a program that creates two HashMap objects, one containing string keys and integer values, and another containing employee IDs as keys and corresponding names as values. Use ArrayLists to store department names.

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        // Test 1: Using HashMap with ArrayList
        System.out.println("Test 1:");
        Map<String, Integer> employeeMap = new HashMap<>();
        employeeMap.put("E001", 5000);
        employeeMap.put("E002", 6000);
        employeeMap.put("E003", 7000);

        List<String> departments = Arrays.asList("IT", "Finance", "Marketing");
        System.out.println("Employee IDs: " + employeeMap.keySet());
        System.out.println("Departments: " + departments);

        // Test 2: Using HashMap with ArrayList (employee names)
        System.out.println("\nTest 2:");
        Map<String, String> employeeNames = new HashMap<>();
        employeeNames.put("E001", "John Doe");
        employeeNames.put("E002", "Jane Smith");
        employeeNames.put("E003", "Bob Johnson");

        departments = Arrays.asList("IT", "Finance", "Marketing");
        System.out.println("Employee Names: " + employeeNames.keySet());
        for (String department : departments) {
            System.out.print(department + ": ");
            for (String name : employeeNames.values()) {
                if (name.startsWith(department)) {
                    System.out.println(name);
                }
            }
            System.out.println();
        }

        // Test 3: Using ArrayList
        List<String> fruits = new ArrayList<>(Arrays.asList("Apple", "Banana", "Cherry"));
        System.out.println("\nTest 3:");
        System.out.println(fruits);

        // Test 4: Using HashMap with ArrayList (similar to test 1)
        System.out.println("\nTest 4:");
        Map<String, Integer> salaries = new HashMap<>();
        salaries.put("E001", 5000);
        salaries.put("E002", 6000);
        salaries.put("E003", 7000);

        fruits = Arrays.asList("IT", "Finance", "Marketing");
        System.out.println("Salaries: " + salaries.keySet());
        for (String fruit : fruits) {
            System.out.print(fruit + ": ");
            for (Integer salary : salaries.values()) {
                if (salary > 6000 && salary % 500 == 0) {
                    System.out.println(salary);
                }
            }
            System.out.println();
        }

        // Test 5: Using HashMap and ArrayList
        System.out.println("\nTest 5:");
        Map<String, List<String>> employees = new HashMap<>();
        employees.put("E001", Arrays.asList("John Doe", "Manager"));
        employees.put("E002", Arrays.asList("Jane Smith", "Senior Developer"));
        employees.put("E003", Arrays.asList("Bob Johnson", "Lead Engineer"));

        fruits = Arrays.asList("IT", "Finance", "Marketing");
        System.out.println("Employees: " + employees.keySet());
        for (String fruit : fruits) {
            System.out.print(fruit + ": ");
            for (List<String> employeeList : employees.values()) {
                if (employeeList.get(0).startsWith(fruit)) {
                    for (String employee : employeeList.subList(1, 2)) {
                        System.out.println(employee);
                    }
                }
            }
            System.out.println();
        }

        // Test 6: Using HashMap and printing JSON
        System.out.println("\nTest 6:");
        Map<String, String> people = new HashMap<>();
        people.put("John Doe", "Manager");
        people.put("Jane Smith", "Senior Developer");
        people.put("Bob Johnson", "Lead Engineer");

        fruits = Arrays.asList("IT", "Finance", "Marketing");
        System.out.println(JSON.toJSONString(people));
    }
}
```

*   Test 4 is similar to test 1 but uses another `ArrayList`.
