### Selecting Elements from HTML Strings using Jsoup

Jsoup is a Java library used for parsing and navigating HTML documents. It provides methods to select elements based on various criteria such as XPath, CSS selectors, or attributes.

#### Problem Statement

Given an HTML string, write a Java function that selects elements based on a specified XPath expression.

#### Solution

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.select.Elements;

public class W3CDomTest {

    public static Document selectXpath(String xpath, String html) {
        // Create a Jsoup document from the HTML string
        Document doc = Jsoup.parse(html);

        // Use the select method to find elements based on the XPath expression
        return doc.select(xpath).first();
    }

    public static void main(String[] args) {
        // Test 1: Selecting an element with an XPath expression
        String htmlString = "<html><body><p>Hello World!</p></body></html>";
        String xpathExpression = "//body//p";
        Document result = selectXpath(xpathExpression, htmlString);
        System.out.println(result.text()); // Output: Hello World!

        // Test 2: Selecting an element using a CSS selector
        xpathExpression = "#header";
        result = selectXpath(xpathExpression, htmlString);
        System.out.println(result); // Output: <p class="header">Hello World!</p>

        // Test 3: Handling empty XPath expressions or HTML strings
        xpathExpression = "";
        htmlString = "";
        try {
            selectXpath(xpathExpression, htmlString);
        } catch (NullPointerException e) {
            System.out.println("Error: Empty XPath expression or HTML string.");
        }
    }
}
```

In the provided code:

1.  We create a `Jsoup` document from an HTML string using the `parse` method.
2.  The `selectXpath` function takes an XPath expression and an HTML string as input, creates a `Document`, and uses the `select` method to find elements based on the specified XPath expression.
3.  We demonstrate three test cases:

    *   Test 1: Selecting an element with an XPath expression (`//body//p`).
    *   Test 2: Selecting an element using a CSS selector (`#header`).
    *   Test 3: Handling empty XPath expressions or HTML strings.

### Working with HTML Documents in Java

In this example, we'll show you how to work with HTML documents in Java using the Jsoup library.

#### Problem Statement

Given an HTML string, write a Java function that selects elements based on a specified XPath expression and prints their text content.

#### Solution

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.select.Elements;

public class W3CDomTest {

    public static void main(String[] args) {
        // Test 1: Selecting an element with an XPath expression
        String htmlString = "<html><body><p>Hello World!</p></body></html>";
        String xpathExpression = "//body//p";
        selectXpath(xpathExpression, htmlString);

        // Test 2: Selecting an element using a CSS selector
        String xpathExpression2 = "#header";
        selectXpath(xpathExpression2, htmlString);

        // Test 3: Handling empty XPath expressions or HTML strings
        String xpathExpression3 = "";
        String htmlString3 = "";
        handleEmptyQueries(xpathExpression3, htmlString3);
    }

    public static void selectXpath(String xpath, String html) {
        // Create a Jsoup document from the HTML string
        Document doc = Jsoup.parse(html);

        // Use the select method to find elements based on the XPath expression
        Elements elements = doc.select(xpath);
        for (Element element : elements) {
            System.out.println(element.text());
        }
    }

    public static void handleEmptyQueries(String xpath, String html) {
        if (xpath.isEmpty() || html.isEmpty()) {
            System.out.println("Error: Empty XPath expression or HTML string.");
        } else {
            selectXpath(xpath, html);
        }
    }

    // Helper function to print the results
    private static void printResults(String xpath, String html) {
        String result = selectXpath(xpath, html);
        if (result != null) {
            System.out.println("XPath: " + xpath + ", Result: " + result);
        } else {
            System.out.println("No elements found with XPath '" + xpath + "'");
        }
    }

    private static void printResults(String xpathExpression2, String htmlString2) {
        selectXpath(xpathExpression2, htmlString2);
    }
}
```

In the provided code:

1.  We create a `Jsoup` document from an HTML string using the `parse` method.
2.  The `selectXpath` function takes an XPath expression and an HTML string as input, creates a `Document`, and uses the `select` method to find elements based on the specified XPath expression.
3.  We demonstrate three test cases:

    *   Test 1: Selecting an element with an XPath expression (`//body//p`).
    *   Test 2: Selecting an element using a CSS selector (`#header`).
    *   Test 3: Handling empty XPath expressions or HTML strings.

By using the Jsoup library, you can easily work with HTML documents in Java and select elements based on various conditions.
