```java
        int count = getTopPrice();
        push(price + count);

        if (top == 0) return -1;
        return stack[top - 1];
    }

    private void push(int value) {
        stack = Arrays.copyOf(stack, top + 1);
        stack[top++] = value;

        return top == 0;
    }
```

Here's a Java implementation of the "Online Stock Span" problem, which calculates the number of days that a price stays above the current day's minimum price.

```java
import java.util.Arrays;

public class OnlineStockSpan {
    private int[] stack;
    private int top;

    public OnlineStockSpan() {
        stack = new int[0];
        top = 0;
    }

    public void add(int price) {
        push(price);
        updateStack();
    }

    private void push(int value) {
        int[] temp = new int[top + 1];
        System.arraycopy(stack, 0, temp, 0, top);
        temp[top++] = value;
        stack = temp;
    }

    private void updateStack() {
        for (int i = 0; i < stack.length - 1; i++) {
            if (stack[i] >= price) break;
            int span = i + 1;
            while (span < stack.length && stack[span] <= stack[i]) {
                span++;
            }
            update(i, span);
        }
    }

    private void update(int low, int high) {
        for (int i = low; i < high; i++) {
            long span = high - low;
            stack[i] += span;
        }
    }

    public boolean isEmpty() {
        return top == 0;
    }

    public int previousHighestPrice(int kthDay) {
        if (kthDay < 1 || kthDay > top) return Integer.MIN_VALUE;
        return stack[kthDay - 1];
    }
}
```

In the above code:

- `add(price)` function adds a price to the span and then updates the stack.
- `push(value)` function pushes a value onto the stack in order of decreasing price. 
- `update(i, span)` function updates all prices from index i to high with a span of (high - low).
- `previousHighestPrice(kthDay)` returns the highest price on or before kthDay.

Example usage:

====================== Iteration #4 ======================
Here's a Java implementation of the "Online Stock Span" problem, which calculates the number of days that a price stays above the current day's minimum price.

```java
import java.util.Stack;

public class Solution {
    public int[] onlineStockSpan(int[] prices) {
        Stack<Integer> stack = new Stack<>();
        int[] result = new int[prices.length];
        
        for (int i = 0; i < prices.length; i++) {
            while (!stack.isEmpty() && prices[stack.peek()] <= prices[i]) {
                stack.pop();
            }
            
            if (stack.isEmpty()) {
                result[i] = i + 1;
            } else {
                result[i] = i - stack.peek();
            }
            
            stack.push(i);
        }
        
        return result;
    }

    public static void main(String[] args) {
        Solution solution = new Solution();
        int[] prices = {100, 80, 75, 130, 56};
        int[] result = solution.onlineStockSpan(prices);
        
        for (int i : result) {
            System.out.print(i + " ");
        }
    }
}
```

In the above code:

- `onlineStockSpan` function takes an array of prices as input and returns an array of stock spans.
- The function uses a stack to keep track of indices that correspond to lower prices.
- For each price in the input array, it pops all indices from the stack that have lower prices than the current price.
- The span for the current price is calculated by subtracting the index at the top of the stack from the current index.
- If the stack is empty, the span is set to the current index plus one.

This solution has a time complexity of O(n) and a space complexity of O(n), where n is the number of prices in the input array.
