**What is the purpose of the `HashMap` class in Java?**

The `HashMap` class in Java is a part of the `java.util` package and is used to store key-value pairs in an unordered collection. It provides fast lookup, insertion, and deletion operations for elements, making it a popular choice for caching, configuration files, and other use cases where efficient data retrieval is essential.

**How does the `HashMap` class work?**

The `HashMap` class uses a hash function to map keys to indices of an array. When a key-value pair is added to the map, the hash function generates a unique index based on the key's value. The corresponding value is then stored at that index in the array. This allows for fast lookup and retrieval of values using their corresponding keys.

**What are some common use cases for the `HashMap` class?**

1.  **Caching**: `HashMap` can be used to cache frequently accessed data, reducing the number of database queries or computational operations.
2.  **Configuration files**: `HashMap` can store configuration file settings and provide fast access to them during runtime.
3.  **Session management**: In web applications, `HashMap` can store user session data, such as logged-in users or their preferences.

Here's an example of using the `HashMap` class in Java:

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        // Create a new HashMap instance
        Map<String, String> fruitMap = new HashMap<>();

        // Add key-value pairs to the map
        fruitMap.put("apple", "red");
        fruitMap.put("banana", "yellow");

        // Retrieve values using their corresponding keys
        System.out.println(fruitMap.get("apple"));  // Output: red
        System.out.println(fruitMap.get("banana"));  // Output: yellow

        // Update a value in the map
        fruitMap.put("apple", "green");
        System.out.println(fruitMap.get("apple"));  // Output: green

        // Remove an element from the map
        fruitMap.remove("banana");
        System.out.println(fruitMap.get("banana"));  // Output: null

        // Check if a key exists in the map
        System.out.println(fruitMap.containsKey("orange"));  // Output: false
    }
}
```

This code demonstrates basic operations such as adding, retrieving, updating, removing, and checking for the existence of elements in a `HashMap`.
