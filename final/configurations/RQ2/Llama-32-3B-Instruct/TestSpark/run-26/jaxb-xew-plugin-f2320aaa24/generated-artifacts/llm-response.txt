```java
public class Main {

    /**
     * This method demonstrates how to iterate over an array using a for loop.
     * 
     * @param array The input array to be processed.
     */
    public static void iterateOverArray(int[] array) {
        // Iterate over the array using a traditional for loop
        for (int i = 0; i < array.length; i++) {
            System.out.println("Element at index " + i + ": " + array[i]);
        }

        // Alternatively, use enhanced for loop
        for (int element : array) {
            System.out.println("Element: " + element);
        }
    }

    public static void main(String[] args) {
        int[] array = {1, 2, 3, 4, 5};
        iterateOverArray(array);
    }
}
```

This code snippet demonstrates two ways to iterate over an array in Java. The first part uses a traditional for loop with an index variable, while the second part utilizes the enhanced for loop, which is more concise and readable.
