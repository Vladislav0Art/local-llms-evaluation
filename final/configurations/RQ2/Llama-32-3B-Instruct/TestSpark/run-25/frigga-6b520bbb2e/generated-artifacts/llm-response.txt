To determine if an application is compatible with a specific version of Android, you can use the `Build.VERSION` class in Java.

Here's how you can do it:

```java
import android.os.Build;

public class AppVersion {
    public static boolean isAppCompatible(String minSdk, String targetSdk) {
        int minSdkInt = Integer.parseInt(minSdk.split("-")[0]);
        int targetSdkInt = Integer.parseInt(targetSdk.split("-")[0]);

        return Build.VERSION.SDK_INT >= minSdkInt &&
               Build.VERSION.SDK_INT <= targetSdkInt;
    }

    public static void main(String[] args) {
        String minSdk = "16-12";
        String targetSdk = "19";

        if (isAppCompatible(minSdk, targetSdk)) {
            System.out.println("The application is compatible with the specified Android version.");
        } else {
            System.out.println("The application is not compatible with the specified Android version.");
        }
    }
}
```

In this code:

- `minSdk` and `targetSdk` are strings representing the minimum and target SDK versions, respectively.
- The `isAppCompatible` method checks if the application's compatibility is within the specified range.
- If the application is compatible, it prints a success message; otherwise, it prints an error message.

To check if an app is compatible with a specific Windows version (Windows XP, Windows Vista, Windows 7, Windows 8, Windows 10), you can use the following Java code:

```java
import java.util.Arrays;

public class AppVersion {
    public static boolean isAppCompatible(String minOs, String targetOs) {
        if (minOs.equals(targetOs)) {
            return true;
        }

        // Check for Windows versions using the system property "os.name" and "os.version"
        String osName = System.getProperty("os.name");
        String osVersion = System.getProperty("os.version");

        int[] minOsVersions = {5, 6, 7}; // corresponding to Windows XP, Vista, 7
        int[] targetOsVersions = {8, 10}; // corresponding to Windows 8, 10

        if (osName.equals("Windows 10") && Arrays.asList(targetOsVersions).contains(Integer.parseInt(osVersion.split("\\.")[0]))) {
            return true;
        } else if (Arrays.asList(minOsVersions).contains(Integer.parseInt(osVersion.split("\\.")[0]))) {
            return false;
        }

        return false;
    }

    public static void main(String[] args) {
        String minOs = "5.1";
        String targetOs = "10.0";

        if (isAppCompatible(minOs, targetOs)) {
            System.out.println("The application is compatible with the specified Windows version.");
        } else {
            System.out.println("The application is not compatible with the specified Windows version.");
        }
    }
}
```

In this code:

- `minOs` and `targetOs` are strings representing the minimum and target OS versions, respectively.
- The `isAppCompatible` method checks if the application's compatibility is within the specified range.
- If the application is compatible, it prints a success message; otherwise, it prints an error message.
