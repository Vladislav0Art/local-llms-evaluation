**Problem:**

Write a Java program that creates an instance of a class named `MyClass` and uses its methods to calculate the area, perimeter, and volume of a rectangle.

```java
public class MyClass {
    public int area(int length) {
        return length * length;
    }

    public double perimeter(int length) {
        return 2 * (length + width);
    }

    public double volume(int length, int width) {
        return length * width * height;
    }
}

public class Main {
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        System.out.println(obj.area(5)); // Output: 25
        System.out.println(obj.perimeter(4)); // Output: 20.0
        System.out.println(obj.volume(6, 8)); // Output: 384
    }
}
```

**Problem:**

Write a Java program that creates two classes `Person` and `Employee`, one with methods to calculate their respective salaries based on years of service.

```java
class Person {
    private int age;
    private String gender;

    public Person(int age, String gender) {
        this.age = age;
        this.gender = gender;
    }

    public void greet() {
        System.out.println("Hello, my name is " + gender + " and I'm " + age + " years old.");
    }
}

class Employee extends Person {
    private int yearsOfService;

    public Employee(int age, String gender, int yearsOfService) {
        super(age, gender);
        this.yearsOfService = yearsOfService;
    }

    public void getSalary() {
        System.out.println("Your salary is: " + (this.getAge() * 10000 / yearsOfService));
    }
}

public class Main {
    public static void main(String[] args) {
        Employee emp = new Employee(35, "male", 20);
        emp.greet();
        emp.getSalary();
    }
}
```

**Problem:**

Write a Java program that creates two classes `Student` and `Teacher`, one with methods to calculate their respective grades based on attendance and attendance percentage.

```java
class Student {
    private String name;
    private int attendencePercentage;

    public Student(String name, int attendencePercentage) {
        this.name = name;
        this.attendencePercentage = attendencePercentage;
    }

    public void printAttendance() {
        System.out.println("Attendance: " + (100 * attendencePercentage / 100));
    }
}

class Teacher extends Student {
    private String subject;

    public Teacher(String name, int attendencePercentage, String subject) {
        super(name, attendencePercentage);
        this.subject = subject;
    }

    public void getGrade() {
        System.out.println("Grade: " + (this.getAttendencePercentage() * 10));
    }
}

public class Main {
    public static void main(String[] args) {
        Teacher teacher = new Teacher("John Doe", 90, "Mathematics");
        System.out.println(teacher.printAttendance());
        System.out.println("Grade: " + teacher.getGrade());
    }
}
```

```java
import java.util.HashMap;
import java.util.Map;

class Student {
    private String name;
    private int attendencePercentage;

    public Student(String name, int attendencePercentage) {
        this.name = name;
        this.attendencePercentage = attendencePercentage;
    }

    public void printAttendance() {
        System.out.println("Attendance: " + (100 * attendencePercentage / 100));
    }
}

class Teacher extends Student {
    private String subject;

    public Teacher(String name, int attendencePercentage, String subject) {
        super(name, attendencePercentage);
        this.subject = subject;
    }

    public void getGrade() {
        System.out.println("Grade: " + (this.getAttendencePercentage() * 10));
    }
}

public class Main {
    public static void main(String[] args) {
        Map<String, Teacher> teachers = new HashMap<>();
        teachers.put("Mathematics", new Teacher("John Doe", 90, "Mathematics"));
        teachers.put("Science", new Teacher("Jane Smith", 85, "Physics"));

        for (Map.Entry<String, Teacher> entry : teachers.entrySet()) {
            System.out.println(entry.getKey() + ":");
            entry.getValue().printAttendance();
            entry.getValue().getGrade();
        }
    }
}
```
