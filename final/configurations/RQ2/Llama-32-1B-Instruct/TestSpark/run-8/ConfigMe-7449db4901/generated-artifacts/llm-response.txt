Here's a complete Java program that demonstrates polymorphism in action:

```java
// Define a parent class called Shape
public class Shape {
    public abstract void draw();

    // A method to print the shape's name and area
    public void printInfo() {
        System.out.println("Shape Name: " + this.getClass().getSimpleName());
        double area = 0;
        for (int i = 0; i <= 10; i++) {
            for (int j = 0; j <= 10; j++) {
                if ((i == 0 || i == 10) && (j == 0 || j == 10)) {
                    area += 1;
                }
            }
        }
        System.out.println("Area: " + area);
    }
}

// Define a child class called Square that extends Shape
public class Square extends Shape {
    private int side;

    // Constructor to initialize the side length
    public Square(int side) {
        this.side = side;
    }

    @Override
    public void draw() {
        System.out.println("Drawing a square with side " + side);
    }

    @Override
    public void printInfo() {
        super.printInfo();
        System.out.println("Side Length: " + side);
    }
}

// Define another child class called Circle that extends Shape
public class Circle extends Shape {
    private double radius;

    // Constructor to initialize the radius
    public Circle(double radius) {
        this.radius = radius;
    }

    @Override
    public void draw() {
        System.out.println("Drawing a circle with radius " + radius);
    }

    @Override
    public void printInfo() {
        super.printInfo();
        System.out.println("Radius: " + radius);
    }
}

public class Main {
    public static void main(String[] args) {
        // Create objects of Shape, Square and Circle classes
        Shape shape = new Square(5);
        Shape shape2 = new Circle(3.5);

        // Use polymorphism to call methods from Shape class
        System.out.println("Shape: " + shape.getClass().getSimpleName());
        shape.draw();
        shape.printInfo();

        System.out.println("\nShape: " + shape2.getClass().getSimpleName());
        shape2.draw();
        shape2.printInfo();
    }
}
```

In this program, we define a parent class called `Shape` with an abstract method `draw()` and a method `printInfo()`. The child classes (`Square` and `Circle`) extend the `Shape` class and override the `draw()` and `printInfo()` methods.

We then create objects of `Square` and `Circle` classes and use polymorphism to call the `draw()` and `printInfo()` methods from the parent class.

```java
public abstract class Animal {
    public abstract void makeSound();

    // A method to print the animal's name
    public String getName() {
        return this.getClass().getSimpleName();
    }
}

class Dog extends Animal {
    private String breed;

    // Constructor to initialize the dog's breed
    public Dog(String breed) {
        this.breed = breed;
    }

    @Override
    public void makeSound() {
        System.out.println("Woof!");
    }

    @Override
    public String getName() {
        return "Dog";
    }
}

class Cat extends Animal {
    private String color;

    // Constructor to initialize the cat's color
    public Cat(String color) {
        this.color = color;
    }

    @Override
    public void makeSound() {
        System.out.println("Meow!");
    }

    @Override
    public String getName() {
        return "Cat";
    }
}

public class Main {
    public static void main(String[] args) {
        // Create objects of Animal, Dog and Cat classes
        Animal animal = new Dog("Golden Retriever");
        Animal animal2 = new Cat("Black");

        // Use polymorphism to call methods from Animal class
        System.out.println("Animal: " + animal.getName());
        animal.makeSound();
        animal.printInfo();

        System.out.println("\nAnimal: " + animal2.getName());
        animal2.makeSound();
        animal2.printInfo();
    }
}
```

In this program, we define an abstract base class `Animal` with two methods: `makeSound()` and `getName()`. The child classes (`Dog` and `Cat`) extend the `Animal` class and override the `makeSound()` method.

We then create objects of `Dog` and `Cat` classes and use polymorphism to call the `makeSound()` and `printInfo()` methods from the parent class.

```java
// Define a parent interface called Vehicle
public interface Vehicle {
    void start();
    void accelerate();
}

class Car extends Vehicle {
    private int speed;

    // Constructor to initialize the car's speed
    public Car(int speed) {
        this.speed = speed;
    }

    @Override
    public void start() {
        System.out.println("Starting the car...");
    }

    @Override
    public void accelerate() {
        if (this.speed < 50) {
            System.out.println("The car is accelerating slowly.");
        } else {
            System.out.println("The car is moving at speed " + this.speed);
        }
    }
}

class Bike extends Vehicle {
    private int speed;

    // Constructor to initialize the bike's speed
    public Bike(int speed) {
        this.speed = speed;
    }

    @Override
    public void start() {
        System.out.println("Starting the bike...");
    }

    @Override
    public void accelerate() {
        if (this.speed < 50) {
            System.out.println("The bike is accelerating slowly.");
        } else {
            System.out.println("The bike is moving at speed " + this.speed);
        }
    }
}

public class Main {
    public static void main(String[] args) {
        // Create objects of Vehicle, Car and Bike classes
        Vehicle vehicle = new Car(30);
        Vehicle vehicle2 = new Bike(40);

        // Use polymorphism to call methods from Vehicle interface
        System.out.println("Vehicle: " + vehicle.getClass().getSimpleName());
        vehicle.start();
        vehicle.accelerate();

        System.out.println("\nVehicle: " + vehicle2.getClass().getSimpleName());
        vehicle2.start();
        vehicle2.accelerate();
    }
}
```

In this program, we define a parent interface `Vehicle` with two methods: `start()` and `accelerate()`. The child classes (`Car` and `Bike`) implement the `Vehicle` interface by providing their own implementation of these methods.

We then create objects of `Car` and `Bike` classes and use polymorphism to call the `start()` and `accelerate()` methods from the parent interface.
