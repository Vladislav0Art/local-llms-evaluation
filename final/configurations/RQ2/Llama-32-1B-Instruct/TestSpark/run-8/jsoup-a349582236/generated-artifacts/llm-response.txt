```java
String tagName = " <span>";
tagName = tagName.replaceAll("[^\\w]", "");

**3. Removing Formatting**

To remove formatting from the tag name, you can use a regular expression that matches any whitespace followed by a word character or non-whitespace character: `\s+[\w]`.

```java
String tagName = "   <span>     ";
tagName = tagName.replaceAll("\\s+\\W+", "");
```

This will replace all one or more whitespace characters with an empty string, effectively removing any leading or trailing whitespace.

**4. Removing Attributes**

To remove attributes from the tag name, you can use a regular expression that matches any attribute name followed by an equals sign: `=\s*`.

```java
String tagName = "id=\"foo\"";
tagName = tagName.replaceAll("\\s*=\\s*", "");
```

This will replace all occurrences of one or more whitespace characters between attribute names and their values with an empty string.

**5. Converting to Space-Only**

To convert the tag name to a space-only format, you can use a regular expression that matches any non-whitespace character: `[^\\w]`.

```java
String tagName = "foo";
tagName = tagName.replaceAll("[^\\w]", " ");
```

This will replace all non-word characters with a single space.
