### Problem: Calculate the sum of all elements in a list of integers

#### Solution
```java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>();
        
        // Test case 1: Add some numbers to the list
        numbers.add(10);
        numbers.add(20);
        numbers.add(30);
        
        System.out.println("Sum of numbers in the list: " + sum(numbers));
    }

    public static int sum(List<Integer> nums) {
        return nums.stream().mapToInt(Integer::intValue).sum();
    }
}
```

#### Explanation

This solution uses Java 8's Stream API to calculate the sum of all elements in a list of integers.

Here's how it works:

1. We create an empty list `numbers`.
2. We add some numbers to the list.
3. The `stream()` method is used to create a stream from the list.
4. The `mapToInt(Integer::intValue)` method converts each integer in the stream into an integer.
5. The `sum()` method calculates the sum of all elements in the stream.

#### Output

```
Sum of numbers in the list: 60
```
