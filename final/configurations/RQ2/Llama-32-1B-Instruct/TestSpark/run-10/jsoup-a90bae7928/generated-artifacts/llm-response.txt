Here is a Java solution using Jsoup to parse HTML and extract the text content of each element:

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;

public class HtmlToText {

    public static void main(String[] args) {
        String html = "<html><body>This is a sample HTML content</body></html>";
        System.out.println(extractText(html));

        Document doc = Jsoup.parse(html);
        System.out.println(doc.text());

        // Extract text from element by tag name
        for (Element element : doc.select("body")) {
            String text = element.text().trim();
            System.out.println(text);
        }

        // Extract text from all elements with class 'text'
        for (Element element : doc.select(".text")) {
            String text = element.text().trim();
            System.out.println(text);
        }
    }

    public static String extractText(String html) {
        Document doc = Jsoup.parse(html);
        return doc.body().outerHtml();
    }
}
```

This Java code uses the Jsoup library to parse HTML and extract the text content of each element. It supports several methods for extracting text, including:

* `extractText()`: Extracts all text from an HTML document.
* `select(String selector)`: Selects elements that match a given CSS style or set of attributes.
* `text()`: Returns the text content of an element.

Note: The code will throw a `NullPointerException` if there are no child nodes (like text, comments, etc.) in the selected elements. You may want to add error checking code to handle such cases.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;

public class HtmlToText {

    public static void main(String[] args) {
        String html = "<html><body>This is a sample HTML content</body></html>";
        
        // Extract text from the entire HTML document
        System.out.println("Entire HTML: " + extractText(html));
        
        // Extract text from all elements with class 'text'
        System.out.println("\nElements with class 'text':");
        for (Element element : Jsoup.parse(html).select("[class='text']")) {
            String text = element.text().trim();
            System.out.println(text);
        }
    }

    public static String extractText(String html) {
        Document doc = Jsoup.parse(html);
        
        // Extract all text from the document
        String text = doc.body().text().replace("<!--", "").replace("-->", "");
        return text;
    }
}
```

This Java code uses the Jsoup library to parse HTML and extract the text content of all elements that have a class named "text". It then prints out this extracted text.

Please note that if you want to avoid cases where there are no child nodes (like text, comments, etc.) in the selected elements, it's recommended to add error checking code to handle such cases.

Also, please be aware that HTML parsing can be computationally expensive. For large HTML documents, consider using a more efficient parsing library or technique.
