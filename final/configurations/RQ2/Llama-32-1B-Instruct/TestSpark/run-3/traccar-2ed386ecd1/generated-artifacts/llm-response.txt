```java
// MyTest class (private method)
public class MyTest {
    private int myPrivateMethod() {
        return 1;
    }

    public static int myStaticMethod() {
        return 2;
    }

    public void myPublicMethod(String a) {
        System.out.println("MyTest: " + a);
    }
}

// MyClass class (private method)
public class MyClass {

    private int myPrivateMethod() {
        return 3;
    }

    // Public method
    public static int myStaticMethod() {
        return 4;
    }

    public void myPublicMethod(String a) {
        System.out.println("MyClass: " + a);
    }
}

// MyOtherClass class (static and instance methods)
public class MyOtherClass {

    public static int myInstanceMethod(MyClass obj) {
        MyClass m = new MyClass();
        // Calling the private method on the object
        m.myPrivateMethod();
        
        System.out.println("MyOtherClass: " + obj.myMethod());
        return 5;
    }

    public void myStaticMethod() {
        System.out.println("MyOtherClass: " + this.myInstanceMethod(this));
    }

    public int myInstanceMethod(MyClass obj) {
        return 6;
    }
}

public class Main {

    public static void main(String[] args) {
        MyTest test = new MyTest();
        MyClass object = new MyClass();

        System.out.println("MyOtherClass: " + MyOtherClass.myStaticMethod());
        MyOtherClass.myInstanceMethod(test);

        int result1 = MyOtherClass.myInstanceMethod(object);
        System.out.println("Result 2 (instance method): " + result1);

        // Calling the static method directly
        int result3 = MyOtherClass.myInstanceMethod(null);
        
        System.out.println("Static method: " + result3);
    }
}
```

This code defines classes `MyTest`, `MyClass`, and `MyOtherClass` with private, public, and instance methods. The program demonstrates how to call these different types of methods using the `main` method.

```java
public class MyClass {
    // Private method that returns 1 when called from a static context, and 3 otherwise
    private int myPrivateMethod() {
        return 1;
    }

    public static void main(String[] args) {
        System.out.println(MyClass.myStaticMethod());  // Prints: static method
        
        MyClass obj = new MyClass();
        
        System.out.println(MyClass.myInstanceMethod(obj));  // Prints: 3
    }
}

class MyOtherClass {
    // Static and instance methods
    public static void main(String[] args) {
        MyClass obj = new MyClass();
        
        System.out.println("MyOtherClass: " + MyClass.getStaticMethod());  
        MyOtherClass.printStaticMethod();  
    
        int result1 = obj.myPrivateMethod();  // Calling the private method on the object
        
        System.out.println("Result 2 (instance method): " + result1);
        
        MyOtherClass.myInstanceMethod(obj);  
        
        printStaticMethod();  

        int result3 = MyOtherClass.myInstanceMethod(null);  
    
        System.out.println("MyOtherClass: " + result3);

        obj.myPrivateMethod();
    }
}

public class Main {
    public static void main(String[] args) {
        MyClass.main(); 
        MyOtherClass.main();
        
        Object object = new Object();

        int result1 = (int) object.getClass().getDeclaredField("myInstanceMethod").get(object);
        System.out.println("Result 4 (instance method): " + result1);

        result1 = (int) MyOtherClass.myStaticMethod();  
    }
}
```

This code demonstrates the use of static and instance methods in Java, including how they are called from other classes. It also shows how to access fields using reflection.
