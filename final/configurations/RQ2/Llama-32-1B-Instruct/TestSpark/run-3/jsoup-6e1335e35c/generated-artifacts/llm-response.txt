Here's a complete example of how to test public class methods in Java using JUnit:

```java
import static org.junit.Assert.*;

public class Calculator {

    public int add(int num1, int num2) {
        return num1 + num2;
    }

    public int subtract(int num1, int num2) {
        if (num2 == 0) {
            throw new ArithmeticException("Subtraction by zero is not allowed");
        }
        return num1 - num2;
    }

    public int multiply(int num1, int num2) {
        return num1 * num2;
    }

    public double divide(int num1, int num2) {
        if (num2 == 0) {
            throw new ArithmeticException("Division by zero is not allowed");
        }
        return (double) num1 / num2;
    }
}

public class CalculatorTest {

    @Test
    public void testAdd() {
        Calculator calculator = new Calculator();
        int result = calculator.add(10, 5);
        assertEquals(15, result); // Expected result is 15
    }

    @Test(expected = ArithmeticException.class)
    public void testSubtractZero() {
        Calculator calculator = new Calculator();
        calculator.subtract(10, 0);
    }

    @Test
    public void testMultiply() {
        Calculator calculator = new Calculator();
        int result = calculator.multiply(4, 6);
        assertEquals(24, result); // Expected result is 24
    }

    @Test
    public void testDivide() {
        Calculator calculator = new Calculator();
        double result = calculator.divide(10, 2);
        assertEquals(5.0, result, 0.01); // Expected result is 5.0 with a small tolerance for floating-point precision issues
    }

    @Test
    public void testDivideByZero() {
        Calculator calculator = new Calculator();
        try {
            calculator.divide(10, 0);
            fail("Expected ArithmeticException");
        } catch (ArithmeticException e) {
            // Expected exception
        }
    }

    @Test
    public void testInvalidDivision() {
        Calculator calculator = new Calculator();
        try {
            calculator.divide(-1, 2);
            fail("Expected ArithmeticException");
        } catch (ArithmeticException e) {
            // Expected exception
        }
    }

    public static void main(String[] args) {
        CalculatorTest.main(args); // Call the main method of CalculatorTest class
    }
}
```

In this example, we have created a Calculator class and a CalculatorTest class that contains methods to test the Calculator class. The Calculator class has four methods: add(), subtract(), multiply(), and divide(). We then create an instance of the CalculatorTest class, call its runTest() method for each test, and print whether each test passed or not.

We also have additional tests to cover edge cases such as division by zero, invalid division, and subtracting from a negative number. These tests check if the Calculator class correctly throws an ArithmeticException when given these special cases.

The main method in the CalculatorTest class calls the main method of the CalculatorTest class, which is required for JUnit to work properly.

Note that this example uses the JUnit 5 framework, which is the latest version of JUnit. If you're using an earlier version of JUnit, you'll need to use a different testing framework or modify the test code accordingly.

public class Calculator {

    public double calculateMean(double[] numbers) {
        int sum = 0;
        for (double num : numbers) {
            sum += num;
        }
        return sum / numbers.length;
    }

    public double calculateProduct(String[] numbers) {
        double product = 1;
        for (String number : numbers) {
            product *= Double.parseDouble(number);
        }
        return product;
    }

    public int calculatePower(int base, int exponent) {
        if (exponent == 0) {
            return 1;
        } else {
            return base * calculatePower(base, exponent - 1);
        }
    }
}
