public abstract class AbstractPkgType {
    public static String getName() {
        return "application/octet-stream";
    }

    protected String filePath;

    public AbstractPkgType(String filePath) {
        this.filePath = filePath;
    }

    @Override
    public boolean isImage() {
        return false;
    }

    @Override
    public boolean isVideo() {
        return false;
    }
}

public class Image extends AbstractPkgType {
    private String path;

    public Image(String path) {
        super(path);
    }

    @Override
    public boolean isImage() {
        return true;
    }
}

public class Video extends AbstractPkgType {
    private String path;

    public Video(String path) {
        super(path);
    }

    @Override
    public boolean isVideo() {
        return true;
    }
}

public class Audio extends AbstractPkgType {
    private String path;

    public Audio(String path) {
        super(path);
    }

    @Override
    public boolean isAudio() {
        return true;
    }
}

public class PkgType implements PkgTypeInterface {
    private String filePath;

    public PkgType(String filePath) {
        this.filePath = filePath;
    }

    public String getPreferredMediaType(String mimeType, String path) {
        if (filePath.equals(path)) {
            return "application/octet-stream";
        } else {
            return getName();
        }
    }

    @Override
    public boolean isImage() {
        return false;
    }

    @Override
    public boolean isVideo() {
        return false;
    }

    @Override
    public boolean isAudio() {
        return true;
    }
}

public interface PkgTypeInterface {
    String getName();
    boolean isImage();
    boolean isVideo();
    boolean isAudio();
}

Here's a Java code that demonstrates how to create different types of files and their respective file extensions:

```java
public class Main {
    public static void main(String[] args) {
        // Create Image File
        PkgType image = new Image("image.jpg");
        System.out.println(image.getPreferredMediaType("image/jpeg", "image.jpg"));  // Output: application/octet-stream

        // Create Video File
        PkgType video = new Video("video.mp4");
        System.out.println(video.getPreferredMediaType("video/mp4", "video.mp4"));  // Output: image/jpeg

        // Create Audio File
        PkgType audio = new Audio("audio.wav");
        System.out.println(audio.getPreferredMediaType("audio/wav", "audio.wav"));  // Output: application/octet-stream

        // Create Text File
        String text = "Hello, World!";
        PkgType text = new Image(text);
        System.out.println(text.getPreferredMediaType("text/plain", "text.txt"));  // Output: application/octet-stream
    }
}
```

In this code:

- We first create three types of files: image.jpg (image/jpeg), video.mp4 (video/mp4), and audio.wav (audio/wav).
- Then, we use the `getPreferredMediaType` method to find the file extension for each type of file.
- The `isImage`, `isVideo`, and `isAudio` methods are used to check if a given MIME type is an image, video, or audio respectively.

Please note that in this code, I have only demonstrated how to create files with specific extensions. In real-world scenarios, you would typically store these types of files in your system's file system for easy access and management.
