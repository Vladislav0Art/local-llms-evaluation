```java
public static void sortColumnsByColumnNames(DataFrame df) {
    List<String> columnNames = new ArrayList<>(df.data.keySet());
    Collections.sort(columnNames);
    for (String columnName : columnNames) {
        String[] columns = df.data.get(columnName).toString().split(", ");
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < columns.length - 1; i++) {
            sb.append(columns[i]).append(",");
        }
        columns[columns.length - 1] = sb.toString().trim();
        DataFrame temp = new DataFrame(new Object[]{columnName, columns});
        df.data.put(columnName, temp);
    }
}
```

* It creates an empty list called `columnNames` that contains all the keys in the input map.
* It splits each string value into individual column names and stores them back into the `columnNames` variable.
* For each column name, it finds its index in the sorted list of column names using the `indexOf()` method.

```java
/**
 * Sorts the columns of a DataFrame by their names.
 */
public static void sortColumnsByColumnNames(DataFrame df) {
    List<String> columnNames = new ArrayList<>(df.data.keySet());
    Collections.sort(columnNames);
    for (int i = 0; i < columnNames.size(); i++) {
        String columnName = columnNames.get(i);
        int index = df.data.get(columnName).toString().indexOf(", ");
        if (index != -1) {
            System.out.println("Column " + columnName + ": " + df.data.get(columnName));
        }
    }
}
```
