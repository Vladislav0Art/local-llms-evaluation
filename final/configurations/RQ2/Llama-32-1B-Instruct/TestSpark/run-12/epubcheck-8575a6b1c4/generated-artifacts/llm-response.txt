Here's a detailed explanation of how to use the `EpubResourceProvider` class:

**Overview**

The `EpubResourceProvider` class is a simple implementation of a resource provider for EPUB files. It allows you to add resources (files) to an EPUB project and retrieve them later.

**How it works**

Here's a step-by-step explanation of how the `EpubResourceProvider` class works:

1. You create an instance of `EpubResourceProvider`.
2. You can add resources to the provider using the `addResource` method, passing in the file name and the resource provider (e.g., `TestEpubResourceProvider`).
3. When you retrieve a resource, you pass in the file name and get back the corresponding resource provider instance.
4. The resource providers are stored in a map with file names as keys.

**Example usage**

Here's an example of how to use the `EpubResourceProvider` class:
```java
public class Main {
    public static void main(String[] args) throws Exception {
        EpubResourceProvider e = new TestEpubResourceProvider();
        
        File file1 = new File("test1.epub");
        addFile(file1);
        
        File file2 = new File("test2.epub");
        addFile(file2);

        EpubResourceProvider provider = new TestEpubResourceProvider().getResource("test1.epub");
        EpubResourceProvider resourceProvider = new EpubResourceProvider();

        e.addResource("test1.epub", provider);
        e.addResource("test2.epub", resourceProvider);

        File resourceFile1 = e.getResource("test1.epub").getResource();

        EpubResourceProvider provider = getResource("test1.epub").getResource();
```

```java
import java.util.HashMap;
import java.util.Map;

public class EpubResourceProvider {
    private Map<String, File> resources = new HashMap<>();

    public void addResource(String fileName, File file) {
        resources.put(fileName, file);
    }

    @Override
    public Map.Entry<String, File> getEntryByFileName(String fileName) {
        return resources.entrySet().stream()
                .filter(entry -> entry.getKey().equals(fileName))
                .findFirst()
                .orElse(null);
    }
}

class TestEpubResourceProvider extends EpubResourceProvider {
    @Override
    public Resource[] getResources() {
        File file1 = new File("test1.epub");
        addFile(file1);

        File file2 = new File("test2.epub");
        addFile(file2);

        return new Resource[]{file1, file2};
    }

    private void addFile(File file) {
        EpubResourceProvider provider = getResource("test1.epub").getResource();
        if (provider == null) throw new RuntimeException("Resource not found for test1.epub");
        resources.put("test1.epub", provider);
    }
}

    private String name;

        this.name = name;

    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;

}
```
