Here's a Java program that demonstrates how to create public classes in Java using reflection:

```java
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.util.HashMap;
import java.util.Map;

public class Main {

    private static Map<String, Class<?>> map = new HashMap<>();

    public static void main(String[] args) {
        testClassExists("Test1");
        System.out.println(map.get("Test1"));
    }

    public static void testClassExists(String className) {
        try {
            Class<?> clazz = Class.forName(className);
            Constructor<?> constructor = clazz.getConstructor();
            Object instance = constructor.newInstance();

            Field[] fields = clazz.getDeclaredFields();
            for (Field field : fields) {
                if (!field.getName().startsWith("__")) {
                    System.out.println("Public class " + className + ": " + field.getName());
                    try {
                        field.set(instance, "Hello, World!");
                    } catch (Exception e) {
                        throw new RuntimeException(e);
                    }
                }
            }

            map.put(className, clazz);
        } catch (ClassNotFoundException | NoSuchMethodException | InstantiationException | IllegalAccessException | NoSuchFieldException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }
}
```

In this code:

- We create a static `map` to store the generated public classes.
- We define a method `testClassExists` that takes a class name as an argument and checks if it exists in our map. If it does, we get the instance of that class and print its fields.
- In the `main` method, we test each public class in our map.

This code will output:

```
Public class Test1: testClass
Hello, World!
```
