```java
import java.lang.reflect.Field;
import java.util.HashMap;
import java.util.Map;

public class Main {
    private static final String PUBLIC_FIELD_PREFIX = "Public";
    private static final String PRIVATE_FIELD_PREFIX = "_Private";

    public void setProp(String key, String value) {
        try {
            if (key.startsWith(PRIVATE_FIELD_PREFIX)) {
                throw new RuntimeException("Cannot access private field");
            }
            this.props.put(key, value);
        } catch (Exception e) {
            System.out.println(e.getMessage());
        }
    }

    public Object getProp(String key) {
        return this.props.get(key);
    }

    public void removeProp(String key) {
        try {
            Field field = Main.class.getDeclaredField(key);
            if (!field.getName().startsWith(PRIVATE_FIELD_PREFIX)) {
                field.setAccessible(true);
                System.out.println(field.get(null));
            }
            this.props.remove(key);
        } catch (Exception e) {}
    }

    public static void main(String[] args) throws Exception {
        // Test 1
        Object instance1 = new Main();
        instance1.setProp("x", "public");
        instance1.printProps();

        // Test 2
        Object instance2 = new Main();
        System.out.println(instance2.getProp("y"));

        // Test 3
        instance2.removeProp("y");

        // Test 4
        instance2.setProp("z", "private");
        instance2.printProps();

        // Test 5
        instance1.printProps();
    }
}
```

This class uses a HashMap to store the properties. The `setProp` method adds or updates a property, and it checks if the key is private or not before attempting to access it. If the key starts with `_Private`, it throws a RuntimeException.

The `getProp` method retrieves a property, but it only accesses public fields. It does not handle private fields or security restrictions (e.g., no access to it).

The `removeProp` method removes a property, and it checks if the key is private before attempting to remove it from the HashMap.
