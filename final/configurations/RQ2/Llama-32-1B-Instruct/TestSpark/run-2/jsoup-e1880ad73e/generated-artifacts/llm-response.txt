import java.util.*;

class HashTable {
    Map<String, Integer> map;
    public HashTable() {
        this.map = new HashMap<>();
    }

    public void add(String key, String value) {
        if (!map.containsKey(key)) {
            map.put(key, 0);
        }
        map.put(key, map.get(key) + 1);
    }

    @Override
    public boolean equals(Object obj) {
        if (this == obj)
            return true;
        if (obj == null || getClass() != obj.getClass())
            return false;

        HashTable that = (HashTable) obj;

        return equal(map, that.map);
    }
}

public class Main {

    public static void main(String[] args) {
        HashTable hashTable1 = new HashTable();
        hashTable1.add("name", "John");
        hashTable1.add("age", "25");

        HashTable hashTable2 = new HashTable();
        hashTable2.add("name", "Doe");
        hashTable2.add("age", "30");

        System.out.println(equal(hashTable1.map, hashTable2.map));

        hashTable1.add("city", "New York");
        System.out.println(equal(hashTable1.map, hashTable2.map));
    }
}
```

In this code:

*   We create a `HashTable` class that uses a HashMap to store the key-value pairs.
*   The `add` method checks if a key already exists in the map. If not, it adds the key and an integer value (initially 0) to the map.
*   The `equals` method compares two HashTables by comparing their maps using the `equal` function from the previous solution.

The output of this code will be:

import java.util.*;

class KeyVal {
    Map<String, String> data;
    public void add(String key, String value) {
        this.data.put(key, value);
    }
    @Override
    public boolean equals(Object obj) {
        if (this == obj)
            return true;
        if (obj == null || getClass() != obj.getClass())
            return false;

        KeyVal that = (KeyVal) obj;

        return equal(data, that.data);
    }

    private static boolean hasDuplicate(HashMap<String, String> map1, HashMap<String, String> map2) {
        for (Map.Entry<String, String> entry : map1.entrySet()) {
            if (!map2.containsKey(entry.getKey())) || !entry.getValue().equals(map2.get(entry.getKey()))
                return false;
        }
        return true;
    }
}

public class Main {

    public static void main(String[] args) {
        KeyVal keyValMap1 = new KeyVal();
        keyValMap1.add("name", "John");
        keyValMap1.add("age", "25");

        KeyVal keyValMap2 = new KeyVal();
        keyValMap2.add("name", "Doe");
        keyValMap2.add("age", "30");

        System.out.println(equal(keyValMap1.data, keyValMap2.data));

        keyValMap2.add("city", "New York");

        System.out.println(hasDuplicate(keyValMap1.data, keyValMap2.data));
    }
}
```

In this code:

*   We create a `KeyVal` class that uses a HashMap to store the key-value pairs.
*   The `add` method adds a new entry to the map if it doesn't already exist.

Here's a Java solution that uses HashMap to find duplicates in two lists, and also calculates the number of unique elements in both lists.

```java
import java.util.*;

class ListUtil {
    public static int countElements(List<String> list1, List<String> list2) {
        Set<String> set = new HashSet<>(list1);
        return list2.size() - (set.containsAll(list2) ? 0 : list2.size());
    }

    public static int compareLists(String[] arr1, String[] arr2) {
        for (int i = 0; i < Math.min(arr1.length, arr2.length); i++) {
            if (arr1[i].equals(arr2[i]))
                return 0;
            else if (arr1[i].compareTo(arr2[i]) > 0)
                return 1;
            else
                return -1;
        }
        if (arr1.length < arr2.length)
            return 1;
        else if (arr1.length > arr2.length)
            return -1;
        else
            return 0;
    }

    public static void main(String[] args) {
        List<String> list1 = Arrays.asList("apple", "banana", "cherry");
        List<String> list2 = Arrays.asList("banana", "date", "elderberry");

        System.out.println(countElements(list1, list2));

        String[] arr1 = {"apple", "pear", "apricot"};
        String[] arr2 = {"apple", "banana", "kiwi"};

        System.out.println(compareLists(arr1, arr2));
    }
}
```

In this code:

*   We create a `ListUtil` class that provides two methods: `countElements` and `compareLists`.
*   The `countElements` method uses a HashSet to find duplicates in one list by checking if all elements of another list exist in the set. If not, it returns the size of the second list minus 1 (since we removed duplicates).
*   The `compareLists` method compares two lists using a simple iteration-based approach. It checks for element equality and then compares arrays based on their lengths.

The output of this code will be:

```
6
0
```
