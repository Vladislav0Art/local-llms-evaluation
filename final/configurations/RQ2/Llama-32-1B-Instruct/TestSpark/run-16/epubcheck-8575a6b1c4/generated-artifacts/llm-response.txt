Here's the revised Java code for the `validateVolume` method:

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class TestValidatingVolume {
    public String validateVolume(String volume) {
        if (volume == null || !volume.matches(".*\\d*\\.?\\d+.*$")) {
            return "Invalid input";
        } else {
            Pattern pattern = Pattern.compile("^-?\\d+(?:\\.\\d+)?$");
            Matcher matcher = pattern.matcher(volume);
            return matcher.matches() ? "Volume is valid: " + volume : "Invalid input";
        }
    }

    public static void main(String[] args) {
        TestValidatingVolume test = new TestValidatingVolume();
        System.out.println(test.validateVolume("123.45"));  // Output: Volume is valid: 123.45
        System.out.println(test.validateVolume("-1.23e-4"));  // Output: Invalid input
    }
}
```

In this revised code, the `validateVolume` method uses a regular expression pattern to check if the provided string matches the expected format (a numeric value with optional decimal points and exponential notation). If it doesn't match, the method returns an error message; otherwise, it checks if the input matches the expected pattern using a `Matcher`, and returns "Invalid input" or "Volume is valid: X.X" depending on whether the input was invalid or valid.

```java
public class TestValidatingVolume {
    public String validateVolume(String volume) {
        if (volume == null || !volume.matches(".*-?\\d+(?:\\.\\d+)?$")) {
            return "Invalid input";
        } else {
            double value = Double.parseDouble(volume);
            return "Value is valid: " + value;
        }
    }

    public static void main(String[] args) {
        TestValidatingVolume test = new TestValidatingVolume();
        System.out.println(test.validateVolume("123.45"));  // Output: Value is valid: 123.45
        System.out.println(test.validateVolume("-1.23e-4"));  // Output: Invalid input
    }
}
```
