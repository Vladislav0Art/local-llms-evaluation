Here's a Java solution for your problem:

**Problem:** Create a class `Calculator` that has two methods, `add()` and `subtract()`, which take two integers as parameters and return their difference.

```java
public class Calculator {
    @PublicMethod
    public int add(int num1, int num2) {
        return num1 + num2;
    }

    @PublicMethod
    public int subtract(int num1, int num2) {
        if (num2 < num1) {
            throw new IllegalArgumentException("Subtraction is not allowed");
        }
        return num1 - num2;
    }
}
```

**Explanation:**

* The `add()` method takes two integers as parameters and returns their sum.
* The `subtract()` method takes two integers as parameters, checks if the second number is less than the first, and throws an `IllegalArgumentException` if this condition is true. Otherwise, it returns the difference between the two numbers.

**Example Use Case:**

```java
public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        int result = calculator.add(10, 5);
        System.out.println("Result of add(): " + result); // Output: 15

        try {
            int result2 = calculator.subtract(10, 5);
            System.out.println("Result of subtract(): " + result2); // Output: 5
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage()); // Output: Subtraction is not allowed
        }
    }
}
```

In this example, we create a `Calculator` object and use its `add()` method to calculate the sum of two numbers. We also demonstrate how to throw an `IllegalArgumentException` when subtraction is attempted.

```java
import java.util.HashMap;
import java.util.Map;

public class BankAccount {
    private Map<String, Double> accounts;
    private String accountNumber;
    private double balance;

    public BankAccount(String accountNumber) {
        this.accounts = new HashMap<>();
        this.accountNumber = accountNumber;
        this.balance = 0.0;
    }

    @PublicMethod
    public void deposit(double amount) {
        if (!accounts.containsKey(accountNumber)) {
            accounts.put(accountNumber, amount);
            System.out.println("Deposited " + amount + ". New balance: " + getBalance());
        } else {
            System.out.println("Account already exists.");
        }
    }

    @PublicMethod
    public void withdraw(double amount) {
        if (accounts.containsKey(accountNumber) && accounts.get(accountNumber) >= amount) {
            accounts.put(accountNumber, accounts.get(accountNumber) - amount);
            System.out.println("Withdrawn " + amount + ". New balance: " + getBalance());
        } else {
            System.out.println("Insufficient funds or account not found.");
        }
    }

    @PublicMethod
    public void checkBalance() {
        if (accounts.containsKey(accountNumber)) {
            System.out.println("Current balance: " + getBalance());
        } else {
            System.out.println("Account does not exist.");
        }
    }

    private double getBalance() {
        return balance;
    }

    @PublicMethod
    public String toString() {
        StringBuilder sb = new StringBuilder();
        sb.append("Account Number: ").append(accountNumber).append("\n");
        sb.append("Balance: ").append(getBalance()).append("\n");
        return sb.toString();
    }
}
```

**Explanation:** This code defines a `BankAccount` class that allows users to manage their bank accounts. The account number is unique and stored in a map along with the balance.

```java
public interface BankInterface {
    @PublicMethod
    void deposit(double amount);

    @PublicMethod
    void withdraw(double amount);

    @PublicMethod
    String toString();
}

class BankImpl implements BankInterface {
    private Map<String, Double> accounts;

    public BankImpl() {
        this.accounts = new HashMap<>();
    }

    @Override
    @PublicMethod
    public void deposit(double amount) {
        if (!accounts.containsKey("12345")) {
            accounts.put("12345", amount);
            System.out.println("Deposited " + amount + ". New balance: " + getBalance());
        } else {
            System.out.println("Account already exists.");
        }
    }

    @Override
    @PublicMethod
    public void withdraw(double amount) {
        if (accounts.containsKey("12345") && accounts.get("12345") >= amount) {
            accounts.put("12345", accounts.get("12345") - amount);
            System.out.println("Withdrawn " + amount + ". New balance: " + getBalance());
        } else {
            System.out.println("Insufficient funds or account not found.");
        }
    }

    @Override
    @PublicMethod
    public String toString() {
        StringBuilder sb = new StringBuilder();
        sb.append("Account Number: ").append(accounts.keySet().iterator().next()).append("\n");
        sb.append("Balance: ").append(getBalance()).append("\n");
        return sb.toString();
    }
}
```
