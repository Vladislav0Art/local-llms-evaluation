```java
public class MyClass {
    private String name;

    public MyClass(String name) {
        this.name = name;
    }

    public void setName(String newName) {
        this.name = newName;
    }

    @Override
    public String toString() {
        return "MyClass{" +
                "name='" + name + '\'' +
                '}';
    }

    public static MyClass getInstance(String name) {
        if (instance1 == null) {
            instance1 = new MyClass(name);
        }
        return instance1;
    }

    private static MyClass instance1;

    public static void main(String[] args) {
        MyClass myInstance1 = MyClass.getInstance("John");
        System.out.println(myInstance1.toString());

        MyClass myInstance2 = MyClass.getInstance("Jane");
        System.out.println(myInstance2.toString());
    }
}
```

In this code:

- We have a class `MyClass` with a private field `name`.
- The class has a method `setName` to set the value of the private field.
- It also has an overridden `toString` method for debugging purposes.
- In the `main` method, we create two instances of `MyClass`, `myInstance1` and `myInstance2`. We then print their names. The second instance is dynamically created using the `getInstance` method which checks if an instance already exists before creating it.

Please note that in a real-world scenario, you would likely want to encapsulate your classes more tightly (i.e., with methods that only modify or return the state of the class) and handle instances of the class in a way that makes sense for your specific use case.

```java
                '}';
    }

    public static void main(String[] args) {

        System.out.println(myInstance1.toString());

            myInstance2.setName("");
            System.out.println(myInstance2.toString());

        } catch (IllegalArgumentException e) {

    }
}
```
