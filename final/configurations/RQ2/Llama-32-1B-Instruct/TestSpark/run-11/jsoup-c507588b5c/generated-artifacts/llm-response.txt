====================== Iteration #5 ======================
Here is the revised solution:

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class TextProcessor {
    public static String normaliseWhitespace(String input) {
        return input.replaceAll("\\s+", " ").trim();
    }

    public static void main(String[] args) {
        System.out.println(normaliseWhitespace("Hello World"));
        System.out.println(normaliseWhitespace("   Hello   World  "));
        System.out.println(normaliseWhitespace(""));
        
        String text = "This is a test string with spaces and some extra characters, including punctuation and special symbols.";
        System.out.println("Before normalisation: " + text);
        System.out.println("After normalisation: " + normaliseWhitespace(text));
    }
}
```

In this revised solution, I have used the `replaceAll` method to replace all whitespace characters with a single space. This will result in a string with no leading or trailing whitespace.

The regular expression pattern `"\\s+"` matches one or more whitespace characters (spaces, tabs, newlines, etc.). The `\S` is a special character class that represents any non-whitespace character (equivalent to `[^\w\s]`). 

I have also added some example use cases in the `main` method.
