====================== Iteration #4 ======================
Here is a Java program that demonstrates polymorphism using methods and objects:

```java
// Base class
class Animal {
    private String name;

    public Animal(String name) {
        this.name = name;
    }

    public void speak() {
        System.out.println(name + " says hello.");
    }
}

// Derived classes
class Dog extends Animal {
    @Override
    public void speak() {
        System.out.println(name + " says woof!");
    }
}

class Cat extends Animal {
    @Override
    public void speak() {
        System.out.println(name + " says meow!");
    }
}

public class Main {
    public static void main(String[] args) {
        // Create objects of different classes
        Animal animal = new Dog("Max");
        Animal animal2 = new Cat("Whiskers");

        // Call methods on the objects
        animal.speak();
        animal2.speak();

        System.out.println("\nPolymorphism demonstration:");
        animal.speak();  // Output: Max says woof!
        animal2.speak();  // Output: Whiskers says meow!
    }
}
```

In this program, we define an `Animal` class with a method `speak()` that prints out a message. We then create two derived classes `Dog` and `Cat`, each implementing the `speak()` method differently.

We demonstrate polymorphism by creating objects of different classes (`Dog` and `Cat`) and calling their `speak()` methods, even though they are all instances of the `Animal` class. This is possible because the compiler knows that a `Dog` object will always be an instance of `Animal`, while a `Cat` object can be an instance of any subclass of `Animal`.
