Here's a Java program that demonstrates a simple calculator class:

```java
public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }

    public int subtract(int a, int b) {
        if (b == 0) {
            throw new ArithmeticException("Subtraction by zero is not allowed");
        }
        return a - b;
    }

    public int multiply(int a, int b) {
        if (a == 0 || b == 0) {
            throw new ArithmeticException("Multiplication by zero is not allowed");
        }
        return a * b;
    }

    public int divide(int a, int b) {
        if (b == 0) {
            throw new ArithmeticException("Division by zero is not allowed");
        }
        return a / b;
    }

    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        
        // Add
        System.out.println(calculator.add(5, 3)); // Output: 8
        
        // Subtract
        try {
            System.out.println(calculator.subtract(10, 4));
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage()); // Output: Division by zero is not allowed
        }
        
        // Multiply
        try {
            System.out.println(calculator.multiply(7, -2)); // Output: -14
        
        // Divide
        try {
            System.out.println(calculator.divide(16, 8));
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage()); // Output: Division by zero is not allowed
        }
    }
}
```

This program creates a `Calculator` class with methods for basic arithmetic operations like addition, subtraction, multiplication, and division. The `main` method demonstrates the usage of these methods using try-catch blocks to handle any potential errors that may occur during execution.

Here's a Java program that calculates the factorial of a given number:

```java
public class FactorialCalculator {
    public static int calculate(int n) {
        if (n < 0) {
            throw new ArithmeticException("Factorial is not defined for negative numbers");
        } else if (n == 0 || n == 1) {
            return 1;
        } else {
            return n * calculate(n - 1);
        }
    }

    public static void main(String[] args) {
        try {
            System.out.println("Factorial of 5: " + calculate(5));
            System.out.println("Factorial of 0: " + calculate(0));
            System.out.println("Factorial of 1: " + calculate(1));
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

This program defines a `FactorialCalculator` class with a `calculate` method that computes the factorial of a given integer using recursion. The `main` method demonstrates how to use this method to calculate the factorial of different numbers.

Here's an alternative approach using iteration instead of recursion:

```java
public class FactorialCalculator {
    public static int calculate(int n) {
        if (n < 0) {
            throw new ArithmeticException("Factorial is not defined for negative numbers");
        } else if (n == 0 || n == 1) {
            return 1;
        } else {
            int result = 1;
            for (int i = 2; i <= n; i++) {
                result *= i;
            }
            return result;
        }
    }

    public static void main(String[] args) {
        try {
            System.out.println("Factorial of 5: " + calculate(5));
            System.out.println("Factorial of 0: " + calculate(0));
            System.out.println("Factorial of 1: " + calculate(1));
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

This version uses a `for` loop to iterate from 2 to `n`, multiplying the result by each number in that range. The final result is then returned.

Here's a Java program that calculates the area of a rectangle:

```java
public class RectangleAreaCalculator {
    public static double calculate(double length, double width) {
        if (length <= 0 || width <= 0) {
            throw new ArithmeticException("Length and width must be positive numbers");
        }
        return length * width;
    }

    public static void main(String[] args) {
        try {
            System.out.println("Area of rectangle with length: " + 10.5 + " and width: " + 20.8);
            System.out.println("Area of rectangle with length: 50 and width: 30");
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }
    }
}
```
