Here's a Java program that fetches data from a MySQL database and prints it to the console.

**Note:** This is a simplified example and doesn't include any error checking or handling. In a real-world application, you would want to add checks to ensure the connection is established correctly, and handle potential errors that may occur.

```java
import java.sql.*;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;

public class Main {
    public static List<String> getRows(int id, String tableName) throws SQLException {
        // Establish a connection to the MySQL database
        Connection conn = DriverManager.getConnection("jdbc:mysql://localhost:3306/mydb", "username", "password");

        // Create a statement object to execute SQL queries
        Statement stmt = conn.createStatement();

        // Fetch all rows from the specified table
        ResultSet rs = stmt.executeQuery("SELECT * FROM " + tableName);

        // Convert the ResultSet to a list of Strings
        List<String> rows = new ArrayList<>();
        while (rs.next()) {
            for (int i = 1; i <= rs.getMetaData().getColumnCount(); i++) {
                rows.add(rs.getString(i));
            }
        }

        return rows;
    }

    public static void main(String[] args) throws SQLException {
        // Fetch data from the 'my_table' table
        List<String> rows = getRows(1, "my_table");
        
        System.out.println(rows);
    }

    private static class Table {
        int id;
        String name;

        public Table(int id, String name) {
            this.id = id;
            this.name = name;
        }
    }
}
```

This program establishes a connection to the MySQL database using `DriverManager.getConnection()`. It then creates a statement object (`Statement stmt`) to execute SQL queries on the specified table. The `getRows()` method fetches all rows from the table and converts them into a list of Strings, which is returned by the `main()` method.

Please replace `"username"`, `"password"`, and `"localhost:3306/mydb"` with your actual MySQL database credentials and connection details.

**Note:** To use this program, you need to have Java Development Kit (JDK) installed on your system. You can download it from the official Oracle website.

Remember that in a real-world application, you would want to handle potential errors that may occur during data fetching or query execution, such as database connection issues or SQL syntax errors.
