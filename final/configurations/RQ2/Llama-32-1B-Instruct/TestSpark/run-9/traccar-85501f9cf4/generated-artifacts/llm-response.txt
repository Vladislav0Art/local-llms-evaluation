I can provide a solution in Java for finding the length of the longest substring without repeating characters.

**Longest Substring Without Repeating Characters**

This problem is known as the "Substring Without Repeating Characters" problem on LeetCode.

### Code Solution
```java
public class MyClass {
    public static int lengthOfLongestSubstring(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }

        char[] chars = s.toCharArray();
        int maxLength = 1;

        // Slide window through the string
        for (int i = 0; i < chars.length; i++) {
            while (i < chars.length - 1 && chars[i] == chars[i + 1]) {
                i++;
            }

            maxLength = Math.max(maxLength, i + 2);
        }
        return maxLength;
    }
}
```
### Explanation

This solution uses a sliding window approach to find the length of the longest substring without repeating characters.

1. Convert the input string to a character array.
2. Initialize `maxLength` to 1 (since an empty string is considered valid).
3. Slide the window through the string, checking each pair of adjacent characters.
4. If we encounter a duplicate character, shrink the window from both ends until the duplicate character is no longer in the window.
5. Update `maxLength` with the maximum length of the substring found so far.

```java
        System.out.println(MyClass.lengthOfLongestSubstring("pwwkew"));   // Output: 3 (wke)
```

====================== Iteration #4 ======================
I can provide a solution in Java for finding the length of the longest substring without repeating characters.

**Longest Substring Without Repeating Characters**

This problem is known as the "Substring Without Repeating Characters" problem on LeetCode.

### Code Solution
```java
import java.util.HashMap;
import java.util.Map;

public class MyClass {
    public static int lengthOfLongestSubstring(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }

        Map<Character, Integer> charIndexMap = new HashMap<>();
        int maxLength = 0;
        int windowStart = 0;

        for (int windowEnd = 0; windowEnd < s.length(); windowEnd++) {
            char rightChar = s.charAt(windowEnd);
            if (charIndexMap.containsKey(rightChar)) {
                windowStart = Math.max(windowStart, charIndexMap.get(rightChar) + 1);
            }
            charIndexMap.put(rightChar, windowEnd);
            maxLength = Math.max(maxLength, windowEnd - windowStart + 1);
        }
        return maxLength;
    }
}
```
### Explanation

This solution uses a sliding window approach to find the length of the longest substring without repeating characters.

1. Create an empty HashMap `charIndexMap` to store the last index of each character in the current window.
2. Initialize `maxLength` to 0 and `windowStart` to 0, which represents the start of the current window.
3. Iterate through the string using a for loop with `windowEnd` as the index pointer.
4. For each character at `windowEnd`, check if it's already in the `charIndexMap`. If it is, update `windowStart` to be the maximum of its current value and the index of the previous occurrence plus 1 (to move the window forward).
5. Update the last index of the current character in the `charIndexMap`.
6. Update `maxLength` with the maximum length of the substring found so far.
7. Return `maxLength` after iterating through all characters.

### Example Use Case

```java
public class TestClass {
    public static void main(String[] args) {
        System.out.println(MyClass.lengthOfLongestSubstring("abcabcbb"));  // Output: 3 (abc)
        System.out.println(MyClass.lengthOfLongestSubstring("bbbbbb"));   // Output: 1 (b)
        System.out.println(MyClass.lengthOfLongestSubstring("pwwkew"));   // Output: 3 (wke)
    }
}
```
This solution has a time complexity of O(n), where n is the length of the input string, and a space complexity of O(min(n, m)), where m is the size of the character set.

```java
import java.util.Map;

public class MyClass {
    public static int lengthOfLongestSubstring(String s) {
        if (s == null || s.length() == 0) {
            return 0;
        }

        Map<Character, Integer> charIndexMap = new HashMap<>();
        int maxLength = 1;

        // Slide window through the string
        for (int i = 0; i < s.length(); i++) {
            char rightChar = s.charAt(i);
            if (charIndexMap.containsKey(rightChar)) {
                // Move the start of the window to the right
                maxLength = Math.max(maxLength, i - charIndexMap.get(rightChar) + 1);
            }

            charIndexMap.put(rightChar, i);
        }
        return maxLength;
    }
}
```
### Explanation

1. Create an empty HashMap `charIndexMap` to store the last index of each character in the current window.
2. Initialize `maxLength` to 1, which represents the minimum possible length of the substring (i.e., the entire string).
3. Iterate through the string using a for loop with `i` as the index pointer.
4. For each character at `i`, check if it's already in the `charIndexMap`. If it is, update `maxLength` with the maximum value between its current value and the difference between its current index and the last occurrence of the previous instance (plus 1 to move the window forward).
5. Update the last index of the current character in the `charIndexMap`.
6. Return `maxLength` after iterating through all characters.
