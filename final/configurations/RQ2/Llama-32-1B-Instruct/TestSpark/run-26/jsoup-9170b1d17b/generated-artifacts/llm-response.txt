```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

public class HtmlExtractor {
    public static void main(String[] args) {
        // Sample HTML string
        String html = "<html><body><h1>This is a heading</h1><p>This is a paragraph of text.</p></body></html>";

        // Extract the title element (the page title)
        Document doc = Jsoup.parse(html);
        Element titleElement = doc.select("title").first();

            System.out.println(titleElement.text());
        } else {
            System.out.println("No title found");
        }
    }
}
```

You can also extract specific elements using CSS selectors or XPath expressions.

For example:

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;

public class HtmlExtractor {
    public static void main(String[] args) {
        // Sample HTML string
        String html = "<html><body><h1>This is a heading</h1><p>This is a paragraph of text.</p></body></html>";

        // Extract all headings (h1-h6)
        Document doc = Jsoup.parse(html);
        Elements headings = doc.select("h1, h2, h3, h4, h5, h6");

        for (Element heading : headings) {
            System.out.println(heading.text());
        }
    }
}
```

In this example, we use `select()` to find all elements with the class names `h1` through `h6`. Each element's text content is printed.
