```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class Main {
    public static String appendKeyVal(String key, Object value) throws IOException, UnsupportedEncodingException {
        StringBuilder content = new StringBuilder();
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(System.in))) {
            System.out.print("Enter the URL: ");
            String url = reader.readLine();

            content.append("key=").append(key).append("\nvalue=").append(value).append("\n").append(url);

            return content.toString();
        }
    }

    public static void main(String[] args) {
        try {
            String response = appendKeyVal("https://example.com/endpoint", "value1");
            System.out.println(response);
        } catch (IOException e) {
            System.out.println(e.getMessage());
        } catch (UnsupportedEncodingException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

*   The response is constructed by concatenating the key-value pair with the URL using string concatenation.
*   In the `main` method, we call `appendKeyVal` with an example URL and value, print the response, and handle potential exceptions.

**Problem:**

Write a Java program that retrieves a JSON data from a URL using the `OkHttp` library and returns the response as a string.

**Solution:**
```java
import okhttp3.OkHttpClient;
import okhttp3.Request;
import okhttp3.Response;

public class Main {
    public static String getJsonData(String url) throws IOException, InterruptedException {
        OkHttpClient client = new OkHttpClient();
        Request request = new Request.Builder()
                .url(url)
                .build();

        try (Response response = client.newCall(request).execute()) {
            return response.body().string();
        }
    }

    public static void main(String[] args) throws IOException, InterruptedException {
        String jsonData = getJsonData("https://jsonplaceholder.typicode.com/todos/1");
        System.out.println(jsonData);
    }
}
```
**Explanation:**

*   The `getJsonData` method takes a URL as input and constructs an HTTP request using the `OkHttpClient`.
*   The `execute()` method sends the request and returns a `Response` object, which is used to retrieve the JSON data.
*   The response body is accessed using the `body().string()` method, which returns a string containing the JSON data.
*   In the `main` method, we call `getJsonData` with an example URL and print the retrieved JSON data.

**Note:**

*   This solution assumes that the server hosting the JSON data responds to HTTP requests in JSON format. If the server requires a specific request method (e.g., POST), additional configuration may be necessary.
*   The `OkHttp` library is used to establish a connection to the server and send the request.

**Problem:**

Write a Java program that retrieves a JSON data from a URL using the `URL` and `HttpURLConnection` classes, parses the JSON response, and returns the result as a string.

**Solution:**
```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.util.Scanner;

public class Main {
    public static String parseJsonData(String url) throws Exception {
        HttpURLConnection connection = (HttpURLConnection) new URL(url).openConnection();
        connection.setRequestMethod("GET");
        connection.connect();

        int responseCode = connection.getResponseCode();
        if (responseCode == 200) {
            Scanner scanner = new Scanner(new BufferedReader(new InputStreamReader(connection.getInputStream())));
            StringBuilder content = new StringBuilder();
            while (scanner.hasNextLine()) {
                content.append(scanner.nextLine());
            }
            scanner.close();
            return content.toString();
        } else {
            throw new Exception("Failed to retrieve data. Status code: " + responseCode);
        }
    }

    public static void main(String[] args) throws Exception {
        String jsonData = parseJsonData("https://jsonplaceholder.typicode.com/todos/1");
        System.out.println(jsonData);
    }
}
```
**Explanation:**

*   The `parseJsonData` method takes a URL as input and uses the `HttpURLConnection` class to establish a connection to the server.
*   The request method is set to GET, which allows the server to return the JSON response.
*   A `Scanner` object is used to read the response content and parse it into a string.
*   In the `main` method, we call `parseJsonData` with an example URL and print the retrieved JSON data.

**Note:**

*   This solution assumes that the server hosting the JSON data responds to HTTP requests in JSON format. If the server requires a specific request method (e.g., POST), additional configuration may be necessary.
*   The `HttpURLConnection` class is used to establish a connection to the server and send the request.

**Example Output:**
