Here is a Java program that uses two methods to print different messages:

```java
public class TestPrinter {
    public static void main(String[] args) {
        testPrinterMethod1();
        testPrinterMethod2();
    }

    private static void testPrinterMethod1() {
        System.out.println("This method will be called first.");
        printMessage("Hello, World!");
    }

    private static void testPrinterMethod2() {
        System.out.println("This method will be called second.");
        System.out.println("This is a different message from the previous one.");
    }

    private static void printMessage(String message) {
        System.out.println(message);
    }
}
```

In this program, we have two methods `testPrinterMethod1()` and `testPrinterMethod2()`. The `main()` method calls these methods in that order. We also have a third method `printMessage(String message)` which simply prints the given message to the console.
