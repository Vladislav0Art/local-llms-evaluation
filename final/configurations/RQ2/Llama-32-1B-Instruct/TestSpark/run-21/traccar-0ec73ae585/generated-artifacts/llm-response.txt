====================== Iteration #4 ======================
Here's a simple Java program that calculates the factorial of a given number:

```java
public class TestClass4 {
    public static int factorial(int n) {
        if (n == 0 || n == 1) {
            return 1;
        } else {
            return n * factorial(n - 1);
        }
    }

    public static void main(String[] args) {
        System.out.println("Factorial of 5: " + TestClass4.factorial(5));
        System.out.println("Factorial of 0: " + TestClass4.factorial(0));
        System.out.println("Factorial of 1: " + TestClass4.factorial(1));
    }
}
```

This program defines a function `factorial` that calculates the factorial of a given number. If the input number is less than or equal to 1, it returns 1 (since the factorial of 0 and 1 is defined as 1). Otherwise, it calls itself recursively with decreasing numbers until it reaches 1.

In the `main` function, we call this function to demonstrate its usage for calculating the factorial of different input numbers.

====================== Iteration #5 ======================
```java
public class TestClass5 {
    public static int findMax(int[] array) {
        if (array.length == 0) {
            return -1; // or throw an exception, depending on your needs
        } else {
            int max = array[0];
            for (int i = 1; i < array.length; i++) {
                if (array[i] > max) {
                    max = array[i];
                }
            }
            return max;
        }
    }

    public static void main(String[] args) {
        System.out.println(TestClass5.findMax(new int[]{5, 2, 9, 1})); // prints: 9
        System.out.println(TestClass5.findMax(new int[]{0, 0, 0})); // prints: -1
    }
}
```

This program defines a function `findMax` that finds the maximum value in an array of integers. It first checks if the input array is empty; if it is, it returns -1 (or throws an exception depending on your needs). Otherwise, it iterates through the array to find the maximum value and returns it.

In the `main` function, we create two arrays with different lengths and call the `findMax` function to demonstrate its usage.
