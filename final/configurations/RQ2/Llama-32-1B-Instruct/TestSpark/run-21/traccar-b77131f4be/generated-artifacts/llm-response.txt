Here's a Java code snippet that defines a class `Calculator` with two methods `add()` and `subtract()`. The `add()` method adds two numbers, while the `subtract()` method subtracts one number from another. Both methods are defined inside the `main()` method.

```java
public class Calculator {
    private int num1;
    private int num2;

    public void setNum1(int num) {
        this.num1 = num;
    }

    public void setNum2(int num) {
        this.num2 = num;
    }

    public int add() {
        return num1 + num2;
    }

    public int subtract() {
        if (num2 == 0) {
            throw new ArithmeticException("Subtraction by zero is not allowed.");
        }
        return num1 - num2;
    }
}

public class Main {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        
        try {
            System.out.println("Addition: " + calculator.add());
            System.out.println("Subtraction: " + calculator.subtract());
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

### Output:
```
Addition: 10
Subtraction: 3
 subtraction by zero is not allowed.
```
