```java
import java.time.*;
import java.time.format.DateTimeFormatter;

public class SolarPositionEstimator {

    public static void main(String[] args) {
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
        LocalDateTime date1 = LocalDateTime.now();
        LocalDateTime date2 = LocalDateTime.of(date1.getYear(), date1.getMonthValue(), date1.getDayOfMonth(), 0, 0);

        System.out.println("Date1: " + date1);
        System.out.println("Date2: " + date2);

        try {
            double estimatedPosition = estimate(date1, date2);
            System.out.println("Estimated solar position: " + estimatedPosition);
        } catch (Exception e) {
            System.out.println("Error estimating solar position: " + e.getMessage());
        }
    }

    public static double estimate(LocalDateTime forDate1, LocalDateTime forDate2) throws Exception {
        int daysDifference = Math.abs(forDate2.getYear() - forDate1.getYear()) * 365;
        int monthsDifference = Math.abs((forDate2.getMonthValue() - forDate1.getMonthValue()) / 12);
        int yearsDifference = forDate1.getDayOfMonth() < forDate2.getDayOfMonth();

        double position = (daysDifference + monthsDifference) / 2.0;

        if (yearsDifference > 0) {
            return position + 30;
        } else {
            return position - 30;
        }
    }
}
```

This solution uses the `estimate` method to calculate the solar position of two dates, and prints out the estimated position. The estimate is based on the assumption that a difference of one year will be approximately equal to a difference in days or months.

Please note that this is an approximation, as the actual solar position can vary due to various factors such as the Earth's elliptical orbit and the tilt of its axis.
