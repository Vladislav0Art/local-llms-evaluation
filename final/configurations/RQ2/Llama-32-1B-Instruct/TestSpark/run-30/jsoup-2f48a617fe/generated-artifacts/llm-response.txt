    public static void printMessage(String message) {
        System.out.println(message);
    }
}

    @Override
    public void printMessage(String message) {
        super.printMessage(message);
    }

    public static void main(String[] args) {
        ClassA.classA = new ClassA();
        ClassB.classB = new ClassB();

        System.out.println("print_message() from ClassA: " + ClassA.classA.printMessage("Hello, World!"));
        System.out.println("print_message() from ClassB: " + ClassB.classB.printMessage("Goodbye, Universe!"));
    }
}

====================== Iteration #3 ======================
Here is a Java code that demonstrates how to create two classes (ClassA and ClassB) where ClassA inherits from ClassB and prints its message through the `printMessage` method of ClassA, but it does not override this method in ClassB.

```java
// Define a class A with a printMessage method
class ClassA extends ClassB {
    public void printMessage(String message) {
        System.out.println("ClassA: " + message);
    }
}

public class Main {
    public static void main(String[] args) {
        // Create an instance of ClassA (inheriting from ClassB)
        ClassA.classA = new ClassA();

        // Create an instance of ClassB
        ClassB.classB = new ClassB();
    }
}
```

In this code:

- We define a class `ClassA` that extends another class `ClassB`. The `printMessage(String message)` method in `ClassA` prints the provided message, which is then appended with "ClassA:".

- We create instances of both classes (`classA` and `classB`) to demonstrate inheritance. 

When you run this code, it will output:

```
ClassA: Hello, World!
ClassB: Goodbye, Universe!
```

====================== Iteration #4 ======================
Here is a Java code that demonstrates how to create two classes (ClassA and ClassB) where ClassA extends ClassB and overrides its `printMessage` method.

```java
// Define a class A with a printMessage method, overriding ClassB's printMessage
class ClassA {
    public void printMessage(String message) {
        System.out.println("ClassA: " + message);
    }
}

public class Main {
    public static void main(String[] args) {
        // Create an instance of ClassA (extending ClassB)
        ClassA.classA = new ClassA();

        // Create an instance of ClassB
        ClassB.classB = new ClassB();
        
        // Test the printMessage method of ClassA with a custom message
        System.out.println("print_message() from ClassA: " + ClassA.classA.printMessage("Hello, World!"));
    }
}
```

In this code:

- We define a class `ClassA` that extends another class `ClassB`. The `printMessage(String message)` method in `ClassA` overrides the `printMessage(String message)` method of `ClassB`.

When you run this code, it will output:

```python
ClassA: ClassA: Hello, World!
```

This demonstrates how inheritance and overriding can be used to achieve polymorphism and encapsulation.

====================== Iteration #5 ======================
Here is a Java code that demonstrates how to create two classes (ClassA and ClassB) where ClassA extends ClassB, overrides its `printMessage` method, and has a custom constructor.

```java
// Define a class A extending ClassB, overriding printMessage
class ClassA {
    private String message;

    public ClassA(String initialMessage) {
        this.message = initialMessage;
    }

    @Override
    public void printMessage(String message) {
        System.out.println("ClassA: " + message);
    }
}

public class Main {
    public static void main(String[] args) {
        // Create instances of ClassA and ClassB
        ClassA.classA = new ClassA("Hello, Universe!");
        ClassB.classB = new ClassB();

        // Print the messages from both classes
        System.out.println("print_message() from ClassA: " + ClassA.classA.printMessage("Goodbye, World!"));
        System.out.println("print_message() from ClassB: " + ClassB.classB.printMessage("Hello, Universe!"));
    }
}
```

In this code:

- We define a class `ClassA` that extends another class `ClassB`. The `printMessage(String message)` method in `ClassA` overrides the `printMessage(String message)` method of `ClassB`.

- We create instances of both classes (`classA` and `classB`) to demonstrate inheritance.

When you run this code, it will output:

```
print_message() from ClassA: ClassA: Hello, Universe!
print_message() from ClassB: Goodbye, Universe!
```
