**Creating the Text File Parser**

We will create a class called `TextFileParser` that can read and parse a text file.

```java
import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class TextFileParser {

    public static void main(String[] args) {
        String filePath = "test.txt"; // replace with your desired file path

        try {
            System.out.println("Reading and parsing the text file...");
            Scanner scanner = new Scanner(new File(filePath));
            while (scanner.hasNextLine()) {
                System.out.println(scanner.nextLine());
            }
            scanner.close();
        } catch (FileNotFoundException e) {
            System.out.println("File not found: " + filePath);
        }
    }

    public static String readFileContent(String filePath) throws FileNotFoundException {
        return readFileToString(filePath);
    }

    private static String readFileToString(String filePath) throws IOException {
        try (InputStream inputStream = new FileInputStream(new File(filePath))) {
            byte[] bytes = inputStream.readAllBytes();
            return new String(bytes).trim(); // remove leading/trailing whitespace
        }
    }
}
```

**How it works:**

1. We create a `Scanner` object to read the file.
2. The while loop reads each line of the file and prints it out.
3. After reading all lines, we close the scanner.
4. The `readFileToString` method reads the entire contents of the file into a string.

**Example Use Cases:**

* Parsing user input from a text file
* Validating data in a CSV or JSON file
* Reading configuration files

Note that this is just a simple example, and you may need to add additional error handling and security measures depending on your specific use case.

```java
import java.io.File;
import java.util.Scanner;

public class TextFileParser {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Enter the name of the file: ");
        String fileName = scanner.nextLine();

        try {
            File file = new File(fileName);
            if (!file.exists()) {
                System.out.println("File not found.");
            } else {
                System.out.println("Reading and parsing the text file...");
                printTextFromFile(file);
            }
        } catch (Exception e) {
            System.out.println("An error occurred: " + e.getMessage());
        }

        scanner.close();
    }

    private static void printTextFromFile(File file) throws Exception {
        try (Scanner scanner = new Scanner(file)) {
            while (scanner.hasNextLine()) {
                System.out.println(scanner.nextLine().trim());
            }
        }
    }
}
```

This application prompts the user to enter a file name, and then attempts to read and parse the text from that file. If the file does not exist or if there's an error reading it, it prints an error message.
