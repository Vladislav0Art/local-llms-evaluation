```java
public class Calculator {
    // Add two numbers
    public static int add(int x, int y) { 
        return x + y; 
    }

    // Subtract one number from another
    public static int subtract(int x, int y) { 
        return x - y; 
    }

    // Multiply two numbers
    public static int multiply(int x, int y) { 
        return x * y; 
    }

    // Divide two numbers
    public static double divide(double x, double y) {
        if (y == 0.0) throw new ArithmeticException("Division by zero is not allowed");
        return x / y;
    }
}

public class TestCalculator {
    // Example of a test class for the calculator class

    public static void main(String[] args) {
        System.out.println(Calculator.add(5, 3));
        System.out.println(Calculator.subtract(10, 4));
        System.out.println(Calculator.multiply(7, 2));

        // Test division with a double result
        try {
            System.out.println(Calculator.divide(10.0, 0.0)); 
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }

        // Test divide by zero with an integer result
        try {
            System.out.println(Calculator.divide(5, 0)); 
        } catch (ArithmeticException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

Note that I changed `int` to `double` in the `divide` method since you are dividing by zero. In Java, division of numbers with different data types can result in a `DivideByZeroError`. The exception will be thrown when attempting to perform division on a non-numeric value.
