It seems like you're asking for a Java class that includes methods to generate random strings of specific length and then call these methods from another class.

Here's an example of how you can structure your code:

```java
import java.util.Scanner;

public class RandomStringGenerator {
    private static final String ALL_CHARACTERS = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
    private static final int LENGTH = 10;
    private static final int COUNT = 5;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.println("Enter the length of the random string:");
        String length = scanner.nextLine();
        try {
            int count = Integer.parseInt(length);
            if (count <= 0 || count > LENGTH) {
                throw new Exception("Length must be between 1 and " + LENGTH);
            }
        } catch (NumberFormatException e) {
            System.out.println("Invalid input. Please enter a number.");
            return;
        }

        String randomString = generateRandomString(count, length);
        printRandomString(randomString);

        scanner.close();
    }

    private static String generateRandomString(int count, int length) {
        StringBuilder sb = new StringBuilder(length);
        for (int i = 0; i < count; i++) {
            sb.append(ALL_CHARACTERS.charAt(scanner.nextInt()));
        }
        return sb.toString();
    }

    private static void printRandomString(String randomString) {
        System.out.println("Generated Random String: " + randomString);
    }
}

class MainClass {
    public static void main(String[] args) {
        PublicMethod.publicMethod(1, 5);
    }
}
```

In this example:

*   The `generateRandomString` method generates a string of the specified length using all possible characters.
*   The `printRandomString` method prints the generated random string to the console.

You can run these classes and they will generate and print random strings.

import java.util.Random;
import java.util.Scanner;

public class MainClass {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Enter the length of the random string (1-10):");
        String length = scanner.nextLine();

        while (!length.matches("\\d+")) {
            System.out.println("Invalid input. Please enter a number.");
            length = scanner.nextLine();
        }

        try {
            int count = Integer.parseInt(length);
            if (count <= 0 || count > 10000) {
                throw new Exception("Length must be between 1 and 10,000");
            }
        } catch (NumberFormatException e) {}

        Random random = new Random();

        System.out.println("Enter 'y' to generate a string with all letters, or 'n' for a string without any special characters:");
        String response = scanner.nextLine().toLowerCase();
        while (!response.equals("y") && !response.equals("n")) {
            System.out.println("Invalid input. Please enter 'y' or 'n'.");
            response = scanner.nextLine().toLowerCase();
        }

        if (response.equals("y")) {
            StringBuilder sb = new StringBuilder(ALL_CHARACTERS.length());
            for (int i = 0; i < ALL_CHARACTERS.length(); i++) {
                sb.append(ALL_CHARACTERS.charAt(random.nextInt(ALL_CHARACTERS.length())));
            }
        } else {
            String characters = ALL_CHARACTERS.substring(1);
            Random random2 = new Random();
            StringBuilder sb = new StringBuilder();

            for (int i = 0; i < count; i++) {
                char c = characters.charAt(random2.nextInt(characters.length()));
                sb.append(c);
            }
        }

        System.out.println("Generated String: " + sb.toString());
    }

    private static String generateRandomString(int count, int length) {
        StringBuilder sb = new StringBuilder(length);
        for (int i = 0; i < count; i++) {
            sb.append(ALL_CHARACTERS.charAt(random.nextInt(ALL_CHARACTERS.length())));
        }
        return sb.toString();
    }

    private static void printRandomString(String randomString) {
        System.out.println("Generated Random String: " + randomString);
    }
}

class PublicMethod {
    public static void main(String[] args) {
        MainClass.main(args);
    }
}
