public class Solution {

    public static int[] findLengthOfShortestPath(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) return new int[]{-1, -1};

        int rows = grid.length;
        int cols = grid[0].length;

        boolean[][] visited = new boolean[rows][cols];

        public static class Node {
            int row, col, dist;

            public Node(int row, int col, int dist) {
                this.row = row;
                this.col = col;
                this.dist = dist;
            }
        }

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (!visited[i][j] && grid[i][j] == 1) {
                    Queue<Node> queue = new LinkedList<>();
                    queue.offer(new Node(i, j, 0));
                    visited[i][j] = true;

                    while (!queue.isEmpty()) {
                        Node currNode = queue.poll();
                        int dist = currNode.dist;
                        if (currNode.row - 2 >= 0 && !visited[currNode.row - 1][currNode.col]) {
                            queue.offer(new Node(currNode.row - 1, currNode.col, dist + 1));
                            visited[currNode.row - 1][currNode.col] = true;
                        }
                        if (currNode.row + 2 < rows && !visited[currNode.row + 1][currNode.col]) {
                            queue.offer(new Node(currNode.row + 1, currNode.col, dist + 1));
                            visited[currNode.row + 1][currNode.col] = true;
                        }
                        if (currNode.col - 2 >= 0 && !visited[currNode.row][currNode.col - 1]) {
                            queue.offer(new Node(currNode.row, currNode.col - 1, dist + 1));
                            visited[currNode.row][currNode.col - 1] = true;
                        }
                        if (currNode.col + 2 < cols && !visited[currNode.row][currNode.col + 1]) {
                            queue.offer(new Node(currNode.row, currNode.col + 1, dist + 1));
                            visited[currNode.row][currNode.col + 1] = true;
                        }
                    }

                    if (queue.size() == 0) return new int[]{grid.length * grid[0].length - 2, 1};
                    else {
                        Node startNode = queue.poll();
                        visited[startNode.row][startNode.col] = false;
                        return new int[]{Math.min(startNode.dist, Math.min(...visited[startNode.row][startNode.col + 1 ..]))};
                    }
                }
            }
        }

        return null;

    }

The problem is to find the length of the shortest path in a grid from the top-left corner to all other corners, where a 1 represents an obstacle and 0 represents a clear area.

```java
public class Solution {

    public static int[] findLengthOfShortestPath(int[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) return new int[]{-1, -1};

        int rows = grid.length;
        int cols = grid[0].length;

        boolean[][] visited = new boolean[rows][cols];

        // Mark the start and end points as visited
        if (grid[0][0] == 1 || grid[rows - 1][cols - 1] == 1) {
            return new int[]{-1, -1};
        }

        Queue<int[]> queue = new LinkedList<>();
        queue.offer(new int[]{0, 0, 1});

        while (!queue.isEmpty()) {
            int[] currNode = queue.poll();
            int x = currNode[0];
            int y = currNode[1];

            if (x == rows - 1 && y == cols - 1) return new int[]{currNode[2]};

            for (int i = -1; i <= 1; i++) {
                for (int j = -1; j <= 1; j++) {
                    if ((i != 0 || j != 0) && (x + i < rows && y + j < cols)) {
                        int currDist = currNode[2] + 1;
                        if (!visited[x + i][y + j]) {
                            visited[x + i][y + j] = true;
                            queue.offer(new int[]{x + i, y + j, currDist});
                        }
                    }
                }
            }
        }

        return null;

    }

    public static void main(String[] args) {
        int[][] grid = {
                {0, 1, 0},
                {1, 1, 0},
                {0, 0, 1}
        };

        System.out.println(findLengthOfShortestPath(grid));
    }
}
```

This solution uses a breadth-first search (BFS) approach to find the shortest path. It marks all clear areas as visited and keeps track of the current node's distance from the start point. The distance is incremented by 1 for each new obstacle it encounters.

The time complexity of this solution is O(m * n), where m and n are the number of rows and columns in the grid, respectively. This is because we visit each cell once. The space complexity is also O(m * n) due to the queue used for BFS.

    public static int[] findLengthOfShortestPath(int[][] grid) {

        boolean[][] visited = new boolean[rows][cols];

        // Mark the start and end points as visited
        if (grid[0][0] == 1 || grid[rows - 1][cols - 1] == 1) {
            for (int i = 0; i < rows; i++) {
                for (int j = 0; j < cols; j++) {
                    visited[i][j] = true;
                }
            }
        }

        int directions[][] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        int shortestPath = Integer.MAX_VALUE;

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (!visited[i][j] && grid[i][j] == 0) {
                    shortestPath = Math.min(shortestPath, dfs(grid, visited, i, j));
                }
            }
        }

        return shortestPath == Integer.MAX_VALUE ? new int[]{-1, -1} : new int[]{shortestPath};
    }

    public static int dfs(int[][] grid, boolean[][] visited, int x, int y) {
        if (x < 0 || x >= grid.length || y < 0 || y >= grid[0].length || grid[x][y] != 0 || visited[x][y]) return -1;
        visited[x][y] = true;

        int shortestPath = Integer.MAX_VALUE;

        for (int i = 0; i < 4; i++) {
            shortDist = dfs(grid, visited, x + directions[i][0], y + directions[i][1]);
            if (shortDist != -1) {
                shortestPath = Math.min(shortestPath, grid[x][y] + shortDist);
            }
        }

        return shortestPath;
    }

    public static void main(String[] args) {
        int[][] grid = {
                {0, 1, 0},
                {1, 1, 0},
                {0, 0, 1}
        };

        System.out.println(findLengthOfShortestPath(grid));
    }
}

For each new direction, it checks if the new node is within the grid boundaries and not an obstacle (marked as 1 in the grid). If it's a clear area, it marks it as visited and updates the shortest path if necessary.

The time complexity of this solution is O(m * n), where m and n are the number of rows and columns in the grid, respectively. This is because we visit each cell once. The space complexity is also O(m * n) due to the queue used for BFS and the visited array.
