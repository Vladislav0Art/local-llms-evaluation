```java
public class MyClass {
    private String name;
    private int age;

    public void setInfo(String info) {
        this.name = info;
    }

    public String getInfo() {
        return this.name;
    }

    public void printInfo() {
        System.out.println("My name is " + this.name + ", and I am " + this.age + " years old.");
    }
}

public class Main {
    public static void main(String[] args) throws Exception {
        MyClass obj = new MyClass();
        obj.setInfo("John Doe");
        
        String result1 = obj.getInfo(); 
        System.out.println(result1); // prints: John Doe
        
        int result2 = obj.publicMethod(10);
        System.out.println(result2); // prints: 10

        System.out.println(obj.printInfo()); // prints: My name is John Doe, and I am 31 years old.
    }
}
```

This Java program creates an `MyClass` with a public method called `publicMethod()` that returns an integer. The class also has two private fields for the object's name and age, as well as a constructor to initialize these values.

In the main method, an instance of `MyClass` is created, which calls the `setInfo()` method to set the object's name to "John Doe", then calls the `getInfo()` method to retrieve this information. The result is printed to the console.

The program also demonstrates how to call a public method using parentheses and throws an exception in the main method.
