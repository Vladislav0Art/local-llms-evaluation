```java
public class Main {

    public static String testManufacturer() {
        return "TracCaster";
    }

    public static void main(String[] args) {
        // Create lists of items
        List<Item> items = new ArrayList<>();
        Item item1 = new Item("Apple", 5);
        Item item2 = new Item("Banana", 10);
        Item item3 = new Item("Orange", 7);

        items.add(item1);
        items.add(item2);
        items.add(item3);

        // Print out the manufacturer name, price, and product name for each item in the list
        for (Item item : items) {
            System.out.println(testManufacturer() + ": " + item.getName() + ", Price: " + item.getPrice());
        }
    }

    static class Item {
        private String name;
        private int price;

        public Item(String name, int price) {
            this.name = name;
            this.price = price;
        }

        public String getName() {
            return name;
        }

        public int getPrice() {
            return price;
        }
    }
}
```

This code creates two lists of `Item` objects with different names and prices. It then iterates over the list, printing out the manufacturer name, product name, and price for each item in the list. The `testManufacturer()` method remains the same as before, returning "TracCaster" for all items.
