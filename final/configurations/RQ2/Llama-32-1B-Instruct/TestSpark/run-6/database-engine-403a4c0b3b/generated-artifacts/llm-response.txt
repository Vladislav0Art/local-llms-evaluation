Here's an example of how you can implement a simple console-based database management system in Java:

```java
import java.util.*;

class Database {
    private Map<String, Map<String, Object>> tables;

    public Database() {
        this.tables = new HashMap<>();
    }

    public void createTable(String tableName, String[] columnNames) {
        if (tables.containsKey(tableName)) {
            System.out.println("Table already exists");
            return;
        }
        List<SQLTerm> sqlTerms = Arrays.asList(
                new SQLTerm("CREATE TABLE " + tableName + " AS SELECT * FROM " + tableName),
                new SQLTerm("DROP TABLE IF EXISTS " + tableName)
        );
        tables.put(tableName, sqlTerms);
    }

    public void dropTable(String tableName) {
        if (!tables.containsKey(tableName)) {
            System.out.println("Table does not exist");
            return;
        }
        List<SQLTerm> sqlTerms = Arrays.asList(
                new SQLTerm("DROP TABLE " + tableName),
                new SQLTerm("IF EXISTS " + tableName)
        );
        tables.remove(tableName);
    }

    public void insertRow(String tableName, String columnNames, String[] values) {
        if (!tables.containsKey(tableName)) {
            System.out.println("Table does not exist");
            return;
        }
        List<SQLTerm> sqlTerms = Arrays.asList(
                new SQLTerm("INSERT INTO " + tableName + " ( " + String.join(", ", columnNames) + ") VALUES (" + String.join(", ", values) + ")"),
                new SQLTerm("SELECT * FROM " + tableName)
        );
        tables.get(tableName).add(sqlTerms);
    }

    public void selectAll(String tableName, String[] operators) {
        if (!tables.containsKey(tableName)) {
            System.out.println("Table does not exist");
            return;
        }
        List<SQLTerm> sqlTerms = Arrays.asList(
                new SQLTerm("SELECT " + String.join(", ", operators)),
                new SQLTerm("FROM " + tableName)
        );
        tables.get(tableName).add(sqlTerms);
    }

    public void printDatabase() {
        if (!tables.isEmpty()) {
            System.out.println("Available Tables:");
            for (Map.Entry<String, List<SQLTerm>> entry : tables.entrySet()) {
                System.out.println(entry.getKey());
                for (SQLTerm sqlTerm : entry.getValue()) {
                    System.out.println(sqlTerm.toString());
                }
            }
        } else {
            System.out.println("No tables available");
        }
    }
}

class SQLTerm {
    private String term;
    private String operator;

    public SQLTerm(String term, String operator) {
        this.term = term;
        this.operator = operator;
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        SQLTerm that = (SQLTerm) o;
        return Objects.equals(term, that.term) && Objects.equals(operator, that.operator);
    }

    @Override
    public int hashCode() {
        return Objects.hash(term, operator);
    }
}

public class Main {
    public static void main(String[] args) {
        Database db = new Database();

        // CREATE TABLE
        String tableName = "test_table";
        String[] columnNames = {"column1", "column2"};
        db.createTable(tableName, columnNames);

        // INSERT DATA
        String[] values = {"value1", "value2"};
        String[][] rows = {
                {"1", "10"},
                {"2", "20"}
        };
        for (String[] row : rows) {
            System.out.println(db.insertRow(tableName, columnNames, row));
        }

        // SELECT DATA
        List<SQLTerm> sqlTerms = Arrays.asList(
                new SQLTerm("SELECT * FROM " + tableName),
                new SQLTerm("FROM " + tableName)
        );
        db.selectAll(tableName, sqlTerms);

        // PRINT DATABASE
        db.printDatabase();
    }
}
```

This program defines a `Database` class with methods to create tables, insert data, select data, and print the database. The `SQLTerm` class represents individual SQL terms.

Please note that this is a simplified example and real-world database management systems require more features, error handling, and security measures.

Here's an example of how you can implement a simple console-based database management system in Java using a graphical user interface (GUI) built on top of Swing:

```java
import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class DatabaseGUI extends JFrame {

    private JTextField tableNameField;
    private JComboBox<String> columnNamesComboBox;
    private JComboBox<String> valuesComboBox;
    private JButton createButton;
    private JButton insertButton;
    private JButton selectButton;
    private JButton printButton;

    public DatabaseGUI() {
        this.setTitle("Database Management System");
        this.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        this.setLayout(new FlowLayout());

        // Create table names
        String[] columnNames = {"column1", "column2"};
        columnNamesComboBox = new JComboBox<>(columnNames);
        createButton = new JButton("Create Table");
        insertButton = new JButton("Insert Data");
        selectButton = new JButton("Select Data");
        printButton = new JButton("Print Database");

        // Create tables
        createTable();
    }

    private void createTable() {
        tableNameField = new JTextField(10);
        createButton.addActionListener(new CreateTableActionListener());

        add(new JLabel("Table Name:"));
        add(tableNameField);

        columnNamesComboBox.add(String.valueOf(columnNames[0]));
        columnNamesComboBox.add(String.valueOf(columnNames[1]));

        createButton.addActionListener(new CreateTableActionListener());

        add(new JLabel("Column Names:"));
        add(columnNamesComboBox);

        valuesComboBox = new JComboBox<>();
        insertButton.addActionListener(new InsertDataActionListener());

        // Create table buttons
        ButtonGroup tableButtons = new ButtonGroup();
        tableButtons.add(createButton);
        tableButtons.add(insertButton);
        tableButtons.add(selectButton);
        tableButtons.add(printButton);

        add(tableNameField, BorderLayout.NORTH);
        add(columnNamesComboBox, BorderLayout.CENTER);
        add(valuesComboBox, BorderLayout.EAST);

        // Create table panel
        JPanel tablePanel = new JPanel();
        tablePanel.setLayout(new GridLayout(4, 2));
        tablePanel.add(createButton);
        tablePanel.add(insertButton);
        tablePanel.add(selectButton);
        tablePanel.add(printButton);
        add(tablePanel, BorderLayout.SOUTH);

        setSize(300, 200);
        setVisible(true);
    }

    private class CreateTableActionListener implements ActionListener {
        public void actionPerformed(ActionEvent e) {
            String tableName = tableNameField.getText();
            System.out.println("Table Name: " + tableName);

            // Create table
            createTable();

            tableNameField.setText("");
        }
    }

    private class InsertDataActionListener implements ActionListener {
        public void actionPerformed(ActionEvent e) {
            String[] values = new String[3];
            for (int i = 0; i < 2; i++) {
                value = JOptionPane.showInputDialog("Enter value " + (i+1));
                if (value != null) {
                    values[i] = value;
                } else {
                    System.out.println("Invalid input");
                    return;
                }
            }

            // Insert data
            String[][] rows = new String[3][2];
            for (int i = 0; i < 3; i++) {
                for (int j = 0; j < 2; j++) {
                    rows[i][j] = values[j].toString();
                }
            }

            // Insert data into table
            if (!tableNames.contains(tableName)) {
                System.out.println("Table does not exist");
                return;
            }

            String[] columnNames = (String[]) columnNamesComboBox.getSelectedItem();
            for (int i = 0; i < 3; i++) {
                rows[i][0] = columnNames[i].toString() + " " + values[i].toString();
            }
            System.out.println("Insert data into table: ");
            for (String row : rows) {
                System.out.println(row);
            }

        }
    }

    private String[] tableNames;
    private int columnNamesIndex;

    public static void main(String[] args) {
        new DatabaseGUI();
    }
}
```

This program defines a `DatabaseGUI` class that creates a GUI with fields for entering table names and columns, buttons to create, insert data, select data, and print the database. The `TableNames` and `columnNamesIndex` variables are used to store the selected table name and column names, respectively.

The `CreateTableActionListener` and `InsertDataActionListener` classes handle the creation of tables and inserting data into them, respectively.

Please note that this is a simplified example and real-world database management systems require more features, error handling, and security measures.
