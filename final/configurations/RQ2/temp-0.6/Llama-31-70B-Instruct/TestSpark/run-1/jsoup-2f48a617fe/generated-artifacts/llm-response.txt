1. Create a test class `CommentTest` in the same package as the `Comment` class.
 2. Add the `@RunWith(MockitoJUnitRunner.class)` annotation to the `CommentTest` class.
 3. In the `CommentTest` class, create a `Comment` instance using the `Comment` constructor with a mocked `String` data.
 4. Create a test method `nodeNameTest` to test the `nodeName()` method. Assert that the `nodeName()` method returns the string "#comment".
 5. Create a test method `getDataTest` to test the `getData()` method. Assert that the `getData()` method returns the mocked data.
 6. Create a test method `setDataTest` to test the `setData(String data)` method. Assert that the `setData(String data)` method returns the instance of `Comment` and the `getData()` method returns the new data.
 7. Create a test method `outerHtmlHeadTest` to test the `outerHtmlHead(Appendable accum, int depth, Document.OutputSettings out)` method. Mock the `Appendable` and `Document.OutputSettings` parameters. Assert that the `outerHtmlHead(Appendable accum, int depth, Document.OutputSettings out)` method calls the `accum.append(out.commentKeyword() + " " + getData())` method.
 8. Create a test method `outerHtmlTailTest` to test the `outerHtmlTail(Appendable accum, int depth, Document.OutputSettings out)` method. Mock the `Appendable` and `Document.OutputSettings` parameters. Assert that the `outerHtmlTail(Appendable accum, int depth, Document.OutputSettings out)` method calls the `accum.append(' ' + out.commentKeyword())` method.
 9. Create a test method `toStringTest` to test the `toString()` method. Assert that the `toString()` method returns the string representation of the `Comment` instance.
