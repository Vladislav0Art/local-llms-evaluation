```java
import static org.junit.Assert.assertEquals;

import org.jsoup.helper.UrlBuilder;
import org.junit.Test;

public class UrlBuilderTest {
    @Test
    public void buildTest() throws Exception {
        URL inputUrl = new URL("http://www.example.com/file.html?key=value");
        UrlBuilder urlBuilder = new UrlBuilder(inputUrl);
        URL outputUrl = urlBuilder.build();
        assertEquals("http://www.example.com/file.html?key=value", outputUrl.toString());
    }

    @Test
    public void appendKeyValTest() throws Exception {
        URL inputUrl = new URL("http://www.example.com/file.html?key=value");
        UrlBuilder urlBuilder = new UrlBuilder(inputUrl);
        urlBuilder.appendKeyVal(new Connection.KeyVal("key1", "value1"));
        URL outputUrl = urlBuilder.build();
        assertEquals("http://www.example.com/file.html?key=value&key1=value1", outputUrl.toString());
    }
}
```

In the `buildTest` method, we create an `UrlBuilder` object with a sample `URL` and then call the `build` method to generate a new `URL`. We then assert that the generated `URL` is the same as the original `URL`.

In the `appendKeyValTest` method, we create an `UrlBuilder` object with a sample `URL` and then call the `appendKeyVal` method with a sample key-value pair. We then call the `build` method to generate a new `URL` and assert that the generated `URL` contains the appended key-value pair.
