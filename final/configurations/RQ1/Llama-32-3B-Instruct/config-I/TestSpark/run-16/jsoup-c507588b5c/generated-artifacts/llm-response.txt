import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class HtmlParser {

    public static void main(String[] args) {
        String htmlString = "<html><body>Hello, World!</body></html>";
        Document doc = Jsoup.parse(htmlString);

        // Extract the title from the HTML
        Element title = doc.title();
        if (title != null) {
            System.out.println("Title: " + title.data());
        } else {
            System.out.println("No title found.");
        }

        // Extract all links on the page
        Elements links = doc.select("a");
        for (Element link : links) {
            System.out.println(link.attr("href"));
        }
    }
}
```

In this example, we use Jsoup to parse an HTML string and extract the title and all links from the document. The `Jsoup.parse()` method is used to parse the HTML string into a Document object, which can be used to navigate and search through the HTML content.

import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class HtmlParser {

    public static void main(String[] args) {
        String htmlString = "<html><body><h1>Document Title</h1><ul><li><a href=\"https://www.example.com\">Example Link</a></li></ul></body></html>";
        Document doc = Jsoup.parse(htmlString);

        // Extract the title from the HTML
        Element titleElement = doc.selectFirst("h1");
        if (titleElement != null) {
            System.out.println("Title: " + titleElement.text());
        } else {
            System.out.println("No title found.");
        }

        // Extract all links on the page
        Elements linkElements = doc.select("a[href]");
        for (Element link : linkElements) {
            System.out.println(link.attr("href"));
        }
    }
}

```

In this example, we use Jsoup to parse an HTML string and extract the title and all links from the document. The `Jsoup.parse()` method is used to parse the HTML string into a Document object, which can be used to navigate and search through the HTML content.

The `selectFirst("h1")` method is used to select the first element with the tag name "h1" in the HTML document. If no such element exists, it returns null.

The `select("a[href]")` method is used to select all elements that match the CSS selector "a[href]". This selector matches any anchor element that has an attribute called "href".
