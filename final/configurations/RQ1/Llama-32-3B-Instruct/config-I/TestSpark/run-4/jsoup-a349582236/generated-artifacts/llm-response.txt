Problem: Extracting links from a webpage using Jsoup.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.select.Elements;

public class Main {

    public static void main(String[] args) {
        String url = "http://example.com";
        Document document = Jsoup.connect(url).get();
        Elements links = document.select("a");
        for (Element link : links) {
            System.out.println(link.attr("href"));
        }
    }
}
```

In this example, we use `Jsoup.connect()` to connect to the specified URL and retrieve its content. We then select all anchor (`<a>`) elements using `select("a")`, which contain links on the webpage. Finally, we iterate through each link element and print out the value of the `href` attribute.

Please replace `"http://example.com"` with the URL you want to extract links from.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class Main {

    public static void main(String[] args) {
        String html = "<html><body><p>This is a paragraph.</p><p>This is another paragraph.</p></body></html>";
        Document document = Jsoup.parse(html);
        Elements paragraphs = document.select("p");
        for (Element paragraph : paragraphs) {
            System.out.println(paragraph.text());
        }
    }
}
```

In this example, we use `Jsoup.parse()` to parse the HTML string into a `Document` object. We then select all paragraph elements using `select("p")`, and iterate through each element, printing out its text content.
