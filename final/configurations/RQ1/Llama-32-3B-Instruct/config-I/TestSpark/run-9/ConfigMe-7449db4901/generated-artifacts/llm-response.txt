Here is an example of a simple CommentsConfiguration class in Java:
```java
import java.util.HashMap;
import java.util.Map;

public class CommentsConfiguration {
    private Map<String, List<String>> comments;

    public CommentsConfiguration() {
        this.comments = new HashMap<>();
    }

    public void addComment(String postId, String comment) {
        if (!comments.containsKey(postId)) {
            comments.put(postId, new ArrayList<>());
        }
        comments.get(postId).add(comment);
    }

    public List<String> getCommentsForPost(String postId) {
        return comments.get(postId);
    }

    public void deleteComment(String postId, int index) {
        if (comments.containsKey(postId)) {
            comments.get(postId).remove(index);
        }
    }

    public Map<String, List<String>> getAllComments() {
        return new HashMap<>(comments);
    }
}
```
This class provides basic methods for adding, retrieving, and deleting comments. It uses a `HashMap` to store the comments, where each post ID is a key and its corresponding value is a list of comments.

You can use this class like this:
```java
CommentsConfiguration config = new CommentsConfiguration();
config.addComment("post1", "This is a comment");
config.addComment("post1", "Another comment");

List<String> commentsForPost = config.getCommentsForPost("post1");
System.out.println(commentsForPost); // [This is a comment, Another comment]

config.deleteComment("post1", 0);
commentsForPost = config.getCommentsForPost("post1");
System.out.println(commentsForPost); // [Another comment]
```
