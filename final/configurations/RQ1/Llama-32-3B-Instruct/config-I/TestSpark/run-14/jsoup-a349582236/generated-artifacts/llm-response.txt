Here's a solution to a common problem: validating user input to ensure it meets certain criteria.

**Problem:** Write a program that takes a string as input from the user and checks if it only contains alphanumeric characters (a-z, A-Z, 0-9) and spaces.

**Solution:**

```python
def validate_input(input_str):
    # Check if all characters in the string are alphanumeric or space
    for char in input_str:
        if not (char.isalnum() or char.isspace()):
            return False
    return True

# Get user input
user_input = input("Please enter a string: ")

# Validate and print result
if validate_input(user_input):
    print("Input is valid.")
else:
    print("Input contains invalid characters.")

# Example usage:
# If the user enters "Hello World", the program will print "Input is valid."
# If the user enters "Hello!World", the program will print "Input contains invalid characters."
```

**Explanation:**

*   We define a function `validate_input` that takes an input string as an argument.
*   Inside the function, we iterate over each character in the input string using a for loop.
*   For each character, we use the `isalnum()` method to check if it's alphanumeric (contains only letters and numbers) or the `isspace()` method to check if it's a space.
*   If any character is neither alphanumeric nor a space, the function immediately returns `False`.
*   If the loop completes without finding any invalid characters, the function returns `True`, indicating that the input string is valid.
*   We call the `validate_input` function with the user's input string and print the result accordingly.

Here's a solution to a common problem: finding the first duplicate in an array of integers.

**Problem:** Write a program that takes an array of integers as input and returns the first duplicate found in the array.

**Solution:**

```python
def find_first_duplicate(arr):
    # Create an empty set to store unique elements
    seen = set()
    
    # Iterate over each element in the array
    for num in arr:
        # If the number is already in the set, it's a duplicate
        if num in seen:
            return num
        # Otherwise, add the number to the set
        seen.add(num)
    
    # If no duplicates are found, return None
    return None

# Example usage:
arr = [1, 2, 3, 4, 5, 2]
print(find_first_duplicate(arr))  # Output: 2

arr = [1, 2, 3, 4, 5]
print(find_first_duplicate(arr))  # Output: None
```

**Explanation:**

*   We define a function `find_first_duplicate` that takes an array of integers as input.
*   Inside the function, we create an empty set called `seen` to store unique elements.
*   We iterate over each element in the array using a for loop.
*   For each element, we check if it's already in the `seen` set. If it is, that means it's a duplicate, so we return the number.
*   If not, we add the number to the `seen` set and continue with the next iteration.
*   If we reach the end of the array without finding any duplicates, we return `None`.
*   The time complexity of this solution is O(n), where n is the length of the input array.

This solution uses a set data structure to efficiently keep track of unique elements in the array. It has a linear time complexity and can handle large inputs.
