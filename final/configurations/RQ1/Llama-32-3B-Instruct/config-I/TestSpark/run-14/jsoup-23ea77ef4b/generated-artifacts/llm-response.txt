3.  If it's an instance of the current class, compare the attributes (or state) of the two objects.
4.  Use the `==` operator to compare the references of the objects, or use the `.equals()` method on the object's attributes to compare their values.

        if (obj instanceof Person) {

            return this.name.equals(other.name) && this.age == other.age;
        }
        return false;
    }

}
