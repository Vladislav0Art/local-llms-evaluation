**Delta-T Calculator**

The Delta-T (ΔT) is the difference between two dates in days. It can be calculated using the following formula:

ΔT = (End Date - Start Date) / 100

Here's the Java code for the Delta-T calculator:

    public double calculateDeltaT(int startDate, int endDate) {
        // Calculate the difference between two dates in days
        return Math.abs((endDate - startDate) / 100.0);
    }

    public boolean assertTrue(boolean condition) {
        if (!condition) {
            throw new AssertionError();
        }
        return true;
    }
}
