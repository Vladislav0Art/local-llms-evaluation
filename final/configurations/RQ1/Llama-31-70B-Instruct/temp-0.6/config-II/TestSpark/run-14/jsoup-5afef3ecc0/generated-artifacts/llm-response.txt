 3. Test `build` method:

```java
    @Test
    public void buildTest() throws MalformedURLException {
        URL url = new URL("http://www.example.com");
        UrlBuilder builder = new UrlBuilder(url);
        URL expectedUrl = new URL("http://www.example.com");
        assertEquals(expectedUrl, builder.build());

        url = new URL("http://www.example.com/test.html?q=test");
        builder = new UrlBuilder(url);
        expectedUrl = new URL("http://www.example.com/test.html?q=test");
        assertEquals(expectedUrl, builder.build());
    }
```

 4. Test `appendKeyVal` method:
```java
    @Test
    public void appendKeyValTest() throws UnsupportedEncodingException {
        KeyVal keyVal = new KeyVal("test", "value");
        URL url = new URL("http://www.example.com");
        UrlBuilder builder = new UrlBuilder(url);
        builder.appendKeyVal(keyVal);
        assertEquals("test=value", builder.q.toString());
    }
```
