Here's a Java program that extracts information from HTML tables and displays it in a human-readable format.

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import java.util.Scanner;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Enter the URL of an HTML table: ");
        String url = scanner.nextLine();

        try {
            Document doc = Jsoup.connect(url).get();
            System.out.println(prettyPrint(doc.html()));
        } catch (Exception e) {
            System.out.println("Error: " + e.getMessage());
        }
    }

    public static String prettyPrint(String text) {
        return Jsoup.parse(text).text().replace("\n", "\n----\n");
    }
}
```

You can run this program and enter the URL of an HTML table when prompted. It will display the information from the table in a formatted way with header lines (like "---- 1 row----") and line breaks for easier reading.
