```java
public class Main {
    public static void main(String[] args) {
        System.out.println(Main.method1());
        int result = Main.method2(10);
        String reversedString = Main.method2(10);
        int result2 = Main.method3("123abc");
        System.out.println(result + " " + result2);
    }

    public static void method1() {
        return "Hello World";
    }

    public static int method2(int x) {
        return x * 2;
    }

    public static String method3(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            sb.append(c);
        }
        return sb.toString();
    }
}
```

In this code:

- `method1()` returns a string.
- `method2(int x)` takes an integer, multiplies it by 2, and returns the result.
- `method3(String s)` takes a string as input, converts it into a character array (because strings are immutable in Java), and then converts this character array back into a new string.

When you run this program, it will print: 
```
Hello World
12
abc
```
