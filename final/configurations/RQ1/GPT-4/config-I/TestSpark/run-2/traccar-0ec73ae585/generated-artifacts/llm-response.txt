Apologies for the confusion. Indeed, the last test cases were trying to access private methods of `WatchProtocolDecoder`, which caused errors during compilation. Unfortunately, we can't make the methods public for testing purpose, as they must remain private based on the current implementation. So I suggest respecting the class design and testing only public method `decode`. Below are the updated tests:

import io.netty.buffer.ByteBuf;

import static org.mockito.Mockito.mock;

    public void decodeNoDeviceSessionTest() throws Exception {
        ByteBuf buf = Unpooled.buffer();
        buf.writeCharSequence("[3G*1234567890*0007*LK]", StandardCharsets.US_ASCII);
        Protocol protocol = mock(Protocol.class);
        Channel channel = mock(Channel.class);
        when(protocol.getDeviceSessionManager()).thenReturn(null);
        
        WatchProtocolDecoder decoder = new WatchProtocolDecoder(protocol);
        assertNull(decoder.decode(channel, mock(SocketAddress.class), buf));
    }

    @Test
    public void decodeDeviceSessionExistsTest() throws Exception {

        WatchProtocolDecoder decoder = new WatchProtocolDecoder(protocol);

    }

        assertNull(decodedPosition.getProtocol());
